# JSON 복사·붙여넣기 — 0.3.4

Figma 선택 시 자동 추출된 속성 표와 요약이 바로 보입니다. JSON 원문은 JSON 보기에서 엽니다. **JSON 복사**도 항상 보이며 유효한 결과에서 활성화됩니다. 별도 메뉴를 열 필요가 없습니다. 성공은 clipboard 작업이 끝난 후에만 알립니다. 비동기 clipboard API가 막히면 선택 텍스트 복사를 시도하며, 그것도 실패하면 JSON 원문을 자동으로 열고 선택한 뒤 다시 복사 버튼을 보여줍니다. Ctrl+C를 이용한 직접 복사도 가능합니다. 선택이 바뀌거나 새 추출이 시작되면 오래된 JSON·성공 표시·수동 복사 영역을 즉시 초기화합니다. 늦게 끝난 이전 복사는 새 선택의 성공으로 표시하지 않습니다.

Chrome의 첫 화면에는 붙여넣기 입력란이 열려 있습니다. JSON 붙여넣기 버튼은 입력란을 열고 포커스합니다. 가져오기 성공 시 입력을 비우고 접으며, 취소는 초안을 비우고 닫으며 기존 디자인을 유지합니다. 파일과 붙여넣기는 같은 schema 1.0 검증을 사용합니다. 잘못된 JSON은 오류와 함께 기존 유효 디자인을 보존합니다.

JSON은 JSON.parse와 명시적 값·타입·크기 검증을 통과해야 합니다. 이름 등은 textContent로 표시하고 HTML이나 JavaScript로 실행하지 않습니다. 1 MiB, 최대 256개 노드와 깊이 16, 중복 ID·예상하지 못한 키·속성별 kind/status/value·색 범위·유한 숫자 등을 검사합니다. unknown/unsupported에는 이유가 필수이며 숫자 0이나 null로 바꾸지 않습니다.

기본 export는 선택한 단일 노드입니다. schema 1.0의 여러 root/children JSON은 수동 노드 선택으로만 지원합니다. 버전 없는 예전 단일 노드나 임의 Figma REST JSON은 자동 변환하지 않습니다. JSON 내용이 DOM 검색/자동 매칭을 지시하지 않습니다. 파일 내보내기와 가져오기도 계속 제공합니다.


0.3.4: JSON 복사 성공은 복사 버튼의 **복사 완료** 문구로 2.5초 동안 표시한 뒤 **JSON 복사**로 돌아옵니다. JSON 아래 성공 안내는 표시하지 않습니다. 반복 복사는 마지막 성공부터 시간을 계산하고, 선택 변경·닫기는 안내를 초기화합니다. 실제 실패의 수동 복사 안내는 유지합니다.
