# 요소 선택·거리·자동 갱신

JSON 없이 웹 탐색부터 시작합니다. 전체 흐름은 [README](../README.md), 설치 경로는 [설치·사용](설치-사용.md)을 참고하세요.

- 요소 선택을 시작한 뒤 **↑/↓**로 부모/이전 자식을 탐색하고 클릭/Enter로 A를 확정합니다.
- 확정된 A의 윤곽과 Border/Padding/Radius 도식을 표시합니다. Border와 Padding만 각 영역 좌상단에 표시하고 Radius는 네 모서리 값으로 표현합니다.
- **Alt+hover**는 같은 문서의 B와 거리를 표시합니다. Alt를 떼면 B/거리만 제거하고 A와 포인터 위치는 유지합니다. 반복 Alt에서 최신 위치를 다시 검사합니다.
- **휠과 Alt+휠은 네이티브 스크롤**입니다. Alt+휠 뎁스 기능은 없습니다. Ctrl 확대·Shift 스크롤도 가로채지 않습니다.
- Esc는 선택/고정 표시를 종료합니다. 이미 수집한 비교 데이터는 유지합니다. 페이지 이동, A 삭제, DevTools 종료 시 관련 오버레이와 이벤트를 정리합니다.

Ctrl+Shift+X는 DevTools가 열린 페이지에서 선택을 켜고 끕니다. 다른 DevTools 패널에서도 시작할 수 있지만 결과를 보려면 FigCheck 탭을 직접 열어야 할 수 있습니다. 닫혀 있으면 F12 안내 배지가 나타납니다. 키 충돌은 `chrome://extensions/shortcuts`에서 조정합니다.

입력 필드·Ctrl/Shift/AltGraph 조합과 다른 단축키는 보호합니다. 측정에 실제 사용한 단독 Alt 해제만 기본 메뉴 동작을 취소합니다. 포커스 회복 경합은 합성 이벤트로 재현·검증했으며 물리적 Windows 메뉴의 동작을 모두 확인한 것은 아닙니다. [Alt 재진입 검증](0.3.22-alt-reentry.md)

## 값의 의미

페이지 도식 중심의 치수와 거리는 축 정렬 렌더 경계의 CSS px입니다. margin, 그림자, 칠해진 픽셀의 거리를 측정하는 것이 아니며 회전·확대된 렌더 크기와 원래 CSS 크기는 다를 수 있습니다. Border/Padding/Radius는 해당 computed CSS 값이며 단일 px로 확정되지 않으면 N/A로 표시합니다. 중첩 도식은 비례 축척이 아닙니다.

거리 측정은 같은 문서의 일반 HTML을 대상으로 합니다. iframe 내부·SVG·열린 Shadow DOM 내부는 미지원 경계입니다. 닫힌 Shadow DOM 내부에는 접근하지 않습니다. 루트 변환·핀치 확대·크기 없는 박스 등의 제한을 표시하며 추정하지 않습니다.

## 자동 갱신

수동 갱신 버튼 없이 활성 패널에서 750ms마다 선택 값의 변화를 확인하고 바뀐 경우에만 다시 수집합니다. 비활성 패널·선택 없음·삭제된 노드에서는 값 확인을 중단합니다. 빠른 선택 변경 시 이전 응답은 버립니다. B를 탐색해도 A는 바뀌지 않습니다.

갱신은 매 프레임 기록이 아니며 약 750ms에 평가 시간과 브라우저 스케줄 제한이 더해질 수 있습니다. 값이 그대로이고 CSS 규칙 출처만 달라지면 후보 근거는 다시 선택할 때 갱신됩니다. CSS 후보는 cascade 승자를 확정하지 않습니다.
