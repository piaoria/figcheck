# 0.3.12 네 코너 로고

최종 사용자 요청에 따라 둥근 사각 테두리를 좌상/우상/우하/좌하 네 코너로 나누었습니다. 좌상 코랄 #cb6557, 우상 블루 #4b83c3, 우하 민트 #278d79, 좌하 라일락 #9a73b5입니다. 코너 사이 작은 여백과 둥근 끝처리를 사용합니다. 가운데 체크는 단색으로, 푸터에서는 테마의 muted 색을 따르고 아이콘에서는 밝은 중립색을 사용합니다. 앞선 두 프레임별 색 분산안은 대체되었습니다.

Figma 공식 심볼이나 배색 배치를 복제하지 않았습니다. 앱의 cool monochrome 테마는 유지하며 그라데이션은 없습니다.

원본 packages/ui/brand/mark.svg의 네 코너 기하·색상을 scripts/brand-icons.mjs가 그대로 재사용합니다. 양쪽 푸터와 Chrome 관리/툴바/DevTools용 PNG가 동일한 형상·색입니다. 16/32/48/128px 및 로컬 커뮤니티용512px를 생성합니다. 밝음·어두움·배지 배경에서 각 코너 색의 대비3:1 이상을 scripts/brand-review.mjs로 확인합니다.

검증: npm run verify, node scripts/brand-review.mjs, npm run test:browser. 실제 크기 캡처 artifacts/brand-icons-light.png 및 brand-icons-dark.png. 실제 Edge/Figma 모의 UI 캡처 artifacts/devtools-brand-*.png 및 figma-brand-*.png. 실제 Figma 호스트는 별도 확인이 필요합니다.

Chrome 확장을 새로고침하고 DevTools를 다시 열거나 Figma 개발 플러그인을 재실행하면 갱신됩니다. 외부 게시/업로드는 하지 않습니다.
