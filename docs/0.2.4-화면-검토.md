# 0.2.4 화면과 한국 서비스 레퍼런스

0.2.4는 기존 비교 기능을 유지하면서 글꼴, 색상, 표와 문구를 정리했습니다. Figma에서는 속성 표를 먼저 보여주고 JSON 복사와 파일 저장을 바로 사용할 수 있습니다. Chrome에서는 전체 속성과 차이만 보기를 유지합니다. 우측 위 `?` 버튼에서 사용 방법과 한계를 확인할 수 있습니다.

## 확인한 공식 화면과 적용 지점

| 공식 자료 | 확인한 구성 | FigCheck에 적용한 내용 | 관찰 범위 |
|---|---|---|---|
| [토스페이먼츠 API 레퍼런스](https://docs.tosspayments.com/reference) | 무채색 본문, 얇은 구분, 선택과 링크의 강조, 한글 본문과 코드의 글꼴 분리 | 본문과 표를 산세리프로 통일하고 JSON과 CSS 코드만 고정폭 글꼴 사용 | 공개 개발자 문서 화면. 독점 브랜드 글꼴은 복제하지 않음 |
| [네이버 클라우드 서버 정보 가이드](https://guide.ncloud-docs.com/docs/server-screen-vpc) | 작은 액션, 검색과 필터, 정렬된 표, 선택한 행의 상세 정보 | 액션을 작게 유지하고 속성 이름과 숫자 열의 정렬을 정리 | 공식 가이드의 공개 콘솔 이미지. 예시 이미지에는 2023년 자료가 포함되며 로그인한 최신 콘솔을 직접 확인한 것은 아님 |
| [채널톡 수신함 도움말](https://docs.channel.io/help/ko/articles/%EC%88%98%EC%8B%A0%ED%95%A8-c2d439c6) | 탐색, 목록, 작업과 상세 영역의 분리, 무채색 중심의 선택 표현 | 디자인 대상과 웹 대상, 결과와 상세 근거를 구분하여 배치 | 공식 문서와 공개 제품 이미지. 문서 글꼴을 제품 전체의 글꼴이라고 단정하지 않음 |

이 자료에서 가져온 것은 정보를 정렬하고 강조를 제한하는 원칙입니다. 각 서비스의 브랜드 색상, 독점 글꼴, 이미지를 복제하지 않았습니다. 다크 화면은 기존 사용 요구를 유지했습니다. 중간점 제거는 이번 사용자 선호를 반영한 것이며, 한국 서비스의 보편 규칙이라는 뜻은 아닙니다.

## 화면에서 달라진 점

- 배경과 표는 중립 회색을 사용합니다. 파랑은 주요 버튼, 선택한 보기, 키보드 포커스에 사용하고 빨강은 차이와 오류에 사용합니다. 상태를 색상만으로 구분하지 않습니다.
- 한글 본문과 표는 13px/20px, 그룹 제목은 14px/20px, 보조 정보는 12px/18px입니다. 이는 FigCheck에서 정한 값이며 참고 서비스의 공식 측정값은 아닙니다.
- 한국어 시스템 글꼴을 사용합니다. Windows에서는 실제 한글 글리프가 설치된 맑은 고딕으로 표시됨을 확인했습니다. 일반 수치는 산세리프와 `tabular-nums`를 사용하며 JSON과 CSS 코드는 고정폭 글꼴을 사용합니다. 새 폰트 패키지나 외부 폰트 요청은 없습니다.
- 그라데이션 마크, 영문 노드 종류 배지, 파랑과 보라의 길이 막대를 제거했습니다. 버전은 작은 일반 텍스트입니다. 실제 추출 색상을 보여주는 색상칩은 유지합니다.
- "여백과 간격", "테두리와 모서리"를 두 앱에서 동일하게 사용합니다. 디자인과 웹 대상은 별도 필드로, 일치 수와 확인 불가 및 사용자 제외 수는 별도 항목으로 표시합니다.
- 사용자 제외와 확인 불가 속성은 계속 구분합니다. 확인 불가 값은 0이나 일치로 처리하지 않으며 점수에서 제외합니다. 웹 값에서 디자인 값을 뺀 차이와 원본 정밀도는 유지합니다.

## 검수 범위

좁은 한글 화면, 긴 이름, 선택 없음, 로딩, 오류, 차이 없음, 전체 28개 결과를 확인했습니다. Figma UI는 320px, Chrome 결과는 360px에서 가로 넘침을 검사했습니다. 긴 이름은 두 줄 안에서 보여주고 원문은 JSON 또는 대상의 툴팁에서 확인할 수 있습니다.

실제 Chromium의 렌더링 글꼴, 숫자 폭 정렬, 버튼 hover, 키보드 포커스, 본문과 상태의 대비를 측정했습니다. 측정한 정상/오류/차이/보조 텍스트와 주 동작 버튼은 4.5:1 이상의 대비를 확인합니다. 이는 모든 픽셀과 모든 환경에 대한 접근성 인증이 아닙니다. `artifacts/figma-presentation.json`, `devtools-presentation.json`에 측정값을 포함합니다.

Chrome 화면은 임시 프로필에 unpacked 확장을 로드한 실제 DevTools 화면입니다. Figma 화면은 빌드한 UI와 실제 추출 코드를 연결한 mock 시험이며 실제 Figma 호스트의 화면이 아닙니다. 물리적 OS 단축키 시험도 미검증입니다. 사용자의 브라우저 전역 설정과 다른 프로젝트는 변경하지 않았습니다.
