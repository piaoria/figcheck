# 0.3.18 — 고정 요소 거리 측정

요소 선택을 시작한 뒤 클릭 또는 Enter로 A를 확정하면 비교 데이터를 수집하고 A의 테두리와 정보를 고정합니다. Alt를 누른 채 같은 문서의 다른 HTML 요소 B 위로 이동하면 두 박스의 거리를 표시합니다. B는 비교 대상으로 다시 수집되지 않습니다.

- 떨어진 박스: 가로·세로 축별 간격을 CSS px로 표시합니다. 대각선 직선거리가 아닙니다.
- 포함된 박스: 바깥 박스의 위·오른쪽·아래·왼쪽 경계까지 네 거리를 표시합니다.
- 맞닿음·겹침·동일 경계를 구별합니다. 겹침 수치는 겹치는 영역의 축별 크기입니다.
- Alt 해제, 포인터 이탈, 창 포커스 상실은 B와 측정선을 지우고 A는 유지합니다. Esc는 고정 표시를 종료하며 이미 수집한 비교 데이터는 유지합니다.
- 다시 선택하면 이전 고정을 정리합니다. 스크롤·크기 및 레이아웃 변화는 표시 위치를 갱신합니다. A 삭제, 페이지 이동, 패널 종료는 고정 표시를 정리합니다.
- 선택 중의 ↑/↓ 및 Alt+휠 깊이 선택은 유지합니다. 고정 후 휠과 일반 클릭은 웹페이지에 전달됩니다.

측정값은 `getBoundingClientRect()`의 뷰포트 기준 축 정렬 border-box 경계입니다. CSS에 작성된 margin/padding, 그림자, 실제 칠해진 픽셀 간격을 뜻하지 않습니다. 소수 CSS px를 보존하고 화면 표시는 소수 셋째 자리까지 반올림합니다. 회전 요소도 축 정렬 바운딩 박스를 기준으로 합니다.

MVP 범위는 같은 문서의 일반 HTML입니다. iframe 내부, 열린 Shadow DOM 내부, SVG는 측정 대상에서 제외하며 닫힌 Shadow DOM 내부에는 접근하지 않습니다. 루트의 transform/perspective/filter/zoom, 핀치 확대, 크기 없는 박스는 측정을 중단하고 제한 안내를 표시합니다. 일반 브라우저 확대에서도 CSS px를 사용하지만 모든 확대율과 실제 OS의 Alt 메뉴 동작을 수동 검증한 것은 아닙니다.

검증 증거는 `artifacts/verification-results.json`, `artifacts/picker-depth-results.json`, `artifacts/browser-results.json` 및 `measurement-*.png`에 기록합니다. 실제 Edge 확장 테스트와 Figma UI 모의 호스트 검증은 실제 Figma 앱 수동 검증을 대신하지 않습니다. README 최종 정리와 커밋·푸시는 보류 상태입니다.
