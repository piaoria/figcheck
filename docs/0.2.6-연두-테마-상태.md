# 0.2.6 연두 테마와 상태 문구

주요 버튼, 선택한 보기, 체크박스, 포커스와 추출된 속성 아이콘을 차분한 연두 계열로 맞췄습니다. 배경과 표는 중립 다크를 유지합니다. 연두 버튼에는 어두운 글자를 사용하며 오류와 실제 차이는 기존 오류색과 텍스트로 구분합니다. 추출된 실제 색상 값은 테마와 별개입니다.

## 단계에 따른 상태 표시

| 내부 상태 또는 상황 | Figma 추출 표 | Chrome 비교 표 | 의미 |
|---|---|---|---|
| supported | 추출됨 | 실제 값과 일치/차이 결과 | 단일 값으로 읽고 정규화한 속성 |
| unknown | 추출 안 됨 | 값 미확인, 비교 제외 | 값이 없거나 대상에 적용되지 않거나 확정하지 못한 값. 상세 이유를 함께 확인 |
| unsupported | 미지원 | 미지원, 비교 제외 | mixed/gradient/복합 값 등 현재 규칙으로 변환하거나 비교할 수 없는 속성 |
| 사용자가 체크 해제 | 해당 없음 | 사용자 제외 | 사용자가 비교에서 뺀 속성. 미지원과 별도 집계 |
| 유효하지 않은 정규화 값 | 해당 오류 표시 또는 원인 | 값 오류, 비교 제외 | 비교 엔진의 방어 검사에서 값이나 단위가 잘못된 경우 |
| 잘못된 JSON, 추출 실패, DOM 선택 오류 | 해당 단계의 오류 메시지 | 해당 단계의 오류 메시지 | 입력이나 추출 과정의 오류. 정상 값이나 일치로 처리하지 않음 |

unknown을 모두 "값 없음"이라고 단정하지 않습니다. 예를 들어 텍스트 노드가 아닌 대상의 글자 속성, 해당 요소에 적용되지 않는 gap, 실제 읽기 실패의 이유가 다릅니다. 기존 JSON의 상세 이유를 그대로 보여주고 상태별 짧은 문구를 추가했습니다. 미지원에는 향후 지원을 약속하는 표현을 사용하지 않습니다.

Figma 상단에는 추출한 수와 추출 안 된 수, 미지원 수를 나눠 보여줍니다. Chrome은 비교한 수와 일치 수, 값 미확인/미지원/값 오류 수, 사용자 제외 수를 구분합니다. 값 미확인과 미지원이 같은 행에 함께 있으면 행 집계는 미지원으로 한 번만 세고, 양쪽 값의 원인은 상세 목록에 모두 표시합니다. 수치가 0인 불필요한 제외 항목은 생략합니다.

## 검증과 설치

정상, hover, disabled 버튼의 글자 대비와 키보드 포커스를 검사했습니다. 비활성 버튼은 중립 회색이고 hover 색으로 바뀌지 않습니다. supported 아이콘은 연두색, 제외된 값의 아이콘은 회색으로 표시하지만 상태 문구와 원인을 함께 제공해 색만으로 구분하지 않습니다.

Figma 320px와 Chrome 360px의 긴 한글 이름과 표, 추출 없음/로딩/오류, 전체 결과, JSON 복사와 재시도, 포함 항목과 도움말, SVG 방향 및 기존 비교 회귀를 검사했습니다. 설치는 `설치-사용.md`를 따르고 화면과 manifest의 앱 버전이 0.2.6인지 확인하세요. JSON schemaVersion은 1.0입니다.

비교 엔진, 값, fixture, 정규화, 허용오차와 분모 제외 규칙은 바꾸지 않았습니다. Chrome 시험은 격리 프로필의 실제 확장과 DevTools이고 Figma 시험은 mock입니다. 실제 Figma 호스트와 물리적 OS 단축키는 미검증입니다. 사용자 브라우저 전역 설정, 모델 설정과 다른 프로젝트는 변경하지 않았습니다.

측정한 주 버튼 대비는 정상 10.55:1, hover 11.96:1, 비활성 5.60:1입니다. 실제 키보드 포커스 테두리는 12.60:1이며 측정한 상태 텍스트의 최소 대비는 6.96:1입니다. 이는 검사한 조합의 결과이고 모든 환경에 대한 접근성 인증은 아닙니다. 원본 측정값은 figma-presentation.json과 devtools-presentation.json에 포함했습니다.
