# 0.3.19 — 거리 표시 UI 정돈

거리 계산, 비교 데이터, 선택/고정/Alt/Esc 이벤트는 0.3.18 동작을 유지하고 오버레이 표현을 정돈했습니다.

- A의 실선과 B의 점선을 유지하면서 테두리를 1px로 줄이고 채움을 약하게 했습니다.
- 거리선은 차분한 청회색 1px 선과 짧은 끝점 눈금으로 표시합니다. 그라데이션과 그림자는 사용하지 않습니다.
- 수치 라벨은 밝은 배경·진한 글자·11px 숫자로 정돈했습니다. CSS px 단위는 정보 영역에 한 번 표시하며 원래 거리 값과 소수 정밀도는 유지합니다.
- 요소 정보는 A/B 배지, 이름, 크기 또는 관계를 짧은 행으로 표시합니다. 긴 이름은 줄임표로 정리하고, 요소를 덜 가리는 화면 모서리를 선택합니다.
- 라벨은 실제 렌더링 크기를 기준으로 화면 안에 배치하며 다른 라벨과 정보 영역을 피해 위치를 선택합니다. 극단적으로 작은 뷰포트에서 모든 오버레이를 완전히 분리한다는 보장은 하지 않습니다.

실제 Edge 확장에서 변경 전·후 간격/포함/겹침 화면을 캡처했습니다. 320×260 화면의 네 모서리에 6×6 요소를 둔 포함 사례에서 네 라벨의 화면 내부 배치, 상호 겹침 및 정보 영역 침범 여부를 검사합니다. 밝은/어두운 페이지 배경도 포함합니다. `artifacts/measurement-before-*.png`, `measurement-*.png`, `picker-depth-results.json`에서 확인할 수 있습니다.

타입 검사·린트·빌드·핵심 테스트와 실제 DevTools 비교 데이터 보존 및 기존 브라우저 회귀 검사를 실행합니다. Figma 검증은 모의 호스트이며 실제 Figma 앱과 물리적 OS Alt 키 동작의 기존 미검증 범위는 그대로입니다. README 최종 정리·커밋·푸시·외부 업로드는 보류합니다.
