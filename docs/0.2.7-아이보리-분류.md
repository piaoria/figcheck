# 0.2.7 아이보리 테마와 분류 헤더

두 앱을 밝은 아이보리 바탕, 구분되는 중립 surface, 진한 텍스트로 통일했습니다. 주요 버튼과 선택은 절제된 짙은 slate 색을 사용합니다. 밝은 테마에서도 오류, 실제 차이, 미지원과 사용자 제외는 문구와 상세 원인으로 구분합니다. 실제 색상 값의 견본은 유지합니다.

Figma의 크기, 여백과 간격, 글꼴, 색상, 테두리와 모서리, 투명도 분류에 의미 있는 단색 SVG 아이콘을 추가했습니다. 기존 개별 속성의 방향 아이콘은 그대로입니다. DevTools 전체 속성 표에도 같은 분류 아이콘을 사용합니다.

## 분류 펼치기와 접기

- Figma 분류 헤더 전체를 클릭하면 접거나 펼칩니다. 우측 chevron이 현재 상태를 나타냅니다.
- Tab으로 헤더에 이동한 뒤 Enter 또는 Space로 펼치거나 접을 수 있습니다. 포커스 표시와 `aria-expanded`를 함께 제공합니다.
- 접힌 내용은 Tab 이동 대상에서 제외됩니다. 아이콘은 중복 낭독하지 않고 보이는 한국어 제목을 유지합니다.
- 사용자가 직접 정한 열림 상태는 현재 플러그인 창 안에서 선택 변경, 잠시 선택 없음, 재추출 후에도 유지됩니다. 헤더에 포커스가 있었다면 같은 분류로 돌아옵니다. 사용자가 다른 버튼에 포커스를 옮겼다면 이를 빼앗지 않습니다.
- 사용자가 직접 열고 닫지 않은 분류는 새 노드의 추출 결과에 맞춰 기본 표시합니다. 플러그인을 완전히 닫고 다시 열면 기본 상태로 시작합니다.

접힘은 브라우저의 기본 `<details>/<summary>` 동작을 사용합니다. 새 라이브러리나 복잡한 분류 동작을 추가하지 않았습니다. DevTools 분류는 기존처럼 정적인 표 헤더이며 추가 접힘 동작은 없습니다.

## 검증 범위

Figma 320px와 Chrome 360px에서 긴 한글 이름과 표의 넘침을 검사했습니다. 분류 아이콘 6개, Enter/Space, 헤더 우측 클릭, 접힌 내용의 키보드 포커스 제외, 선택 변경 후 사용자 상태와 헤더 포커스 유지도 실제 Chromium에서 검사했습니다. 정상/hover/비활성 버튼과 상태 텍스트, 키보드 포커스 대비를 측정했고 도움말, JSON 복사/붙여넣기, 미지원 이유, 체크 필터와 비교 회귀를 함께 확인합니다.

Chrome은 격리 프로필의 실제 확장과 DevTools 화면입니다. Figma는 빌드한 UI와 추출 코드를 연결한 mock이며 실제 Figma 호스트는 미검증입니다. 물리적 OS 단축키도 미검증 상태입니다. 앱 버전은 0.2.7, JSON schemaVersion은 1.0입니다. 비교 엔진과 정규화 및 fixture 값, 사용자 설정과 다른 프로젝트는 변경하지 않았습니다.
