# FigCheck 0.3.2 사용·변경 안내

Figma 노드 하나와 사용자가 선택한 웹 DOM 하나를 비교합니다. JSON·점수·허용오차·정밀도·테마·글꼴·요소 선택 흐름은 그대로입니다.

## 도식 읽기

round 아이콘과 값은 border 경계 안의 좌측 상단·우측 상단·좌측 하단·우측 하단에 배치합니다. 외곽의 별도 모서리 영역을 없애고 방향별 border 두께, padding과 다른 행으로 구분하여 겹침을 방지합니다. 네 모서리는 공통 속성 아이콘과 원본 수치를 사용합니다. N/A는 이유가 있는 미확인·미지원 값이며 0으로 바꾸지 않습니다.

border 안에 padding을 중첩한 박스는 유지합니다. 가운데 크기 수치 위의 **작은 독립 직사각형 SVG 미리보기만 제거**했습니다. 너비·높이 숫자와 아이콘은 남습니다. 이제 도형 배율을 제공하지 않으며 중첩 박스의 크기·영역 폭·선 두께는 분류용 기호입니다. 실제 크기는 숫자로 판단하세요. +138px 같은 차이와 작은 소수 값은 기존 엔진 판정을 그대로 따릅니다.

margin은 수집하지 않아 생략합니다. row/column gap은 별도 표시합니다. Figma content 크기는 stroke/layout 포함 정보가 없어 추정하지 않습니다. 웹 content는 모든 관련 값과 box-sizing·overflow·scrollbar-gutter 조건이 확인될 때만 계산합니다. 미지원이나 음수 결과는 N/A이며 임의로 clamp하지 않습니다.

도식 값은 버튼입니다. Enter/Space로 표의 해당 속성 또는 자세한 이유로 이동합니다. 넓은 DevTools에서는 Figma/웹을 나란히, 좁은 패널에서는 위아래로 보여줍니다. Figma 플러그인은 선택 노드 한 면만 보여줍니다.

## Figma 색상 정렬

Figma 플러그인의 표와 색상 미리보기에서 **견본과 색상 값을 우측 끝에 정렬**했습니다. 속성명은 좌측에 두고 견본과 값 사이 간격을 동일하게 유지합니다. HEX/RGB/HSL의 긴 값은 자신의 영역 안에서 줄바꿈합니다. Chrome 확장의 색상 정렬은 변경하지 않았습니다.

색상 표기 설정은 표시만 바꾸며 JSON·RGBA·비교 점수를 바꾸지 않습니다. 미리보기는 paint alpha만 표현하며 노드나 조상 opacity 합성은 재현하지 않습니다. gradient/P3/복합 값은 임의의 단색으로 그리지 않습니다. 글꼴은 메타데이터만 표시하고 실제 샘플 글꼴을 다운로드하거나 렌더링하지 않습니다.

## 설치와 검증

사용 중인 개발 플러그인과 확장을 다시 로드해 새 빌드를 사용하세요. Figma는 `apps/figma-plugin/dist/manifest.json`, Chrome unpacked 확장은 `apps/chrome-extension/dist`입니다. [설치·사용](설치-사용.md)을 확인하세요.

typecheck/lint/tests/build와 핵심 44개, 실제 격리 Chrome DevTools 96개, Figma mock 및 실제 빌드 UI 53개 검사를 통과했습니다. 라이트/다크·320px, 비대칭 모서리, N/A, 긴 소수, 매우 작은 크기, 겹침과 아이콘, 키보드·JSON 불변, Figma HEX/RGB/HSL 우측 정렬을 확인합니다. 캡처는 `artifacts/*corner-extreme*.png`, `figma-color-right-*.png`와 양 테마 시각 비교 이미지에 포함됩니다.

실제 Figma 데스크톱 호스트와 물리 OS 단축키 시험은 미검증입니다. Figma 이미지는 mock 호스트 UI입니다. 사용자 브라우저 전역 설정·실제 확장 설치와 모델 설정·다른 프로젝트는 변경하지 않았습니다. 새 권한과 분석 데이터 외부 전송을 추가하지 않았습니다.
