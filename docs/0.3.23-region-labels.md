# 0.3.23 — 오버레이 영역 라벨

공유 박스 도식의 `region-label` 배치 규칙(영역 좌상단, 위쪽 여백)을 작은 오버레이에도 적용했습니다. Border와 Padding은 각 영역 좌상단에 한 번씩만 표시합니다. 별도 Radius 제목과 렌더 경계/CSS px 안내는 제거하고, 네 모서리 아이콘·수치와 중심 치수의 px 단위는 유지합니다. 수치는 기존처럼 CSS px이며 도식은 비례 축척이 아닙니다.

기존 Alt 재진입, 네이티브 휠 스크롤, 고정 A와 B 측정, 탐색 우선 화면 및 자동 갱신 동작은 유지합니다. 실제 브라우저에서 라벨 위치·중복·수치와 겹침 및 320px 작은 화면을 확인합니다. README 최종 정리·커밋·푸시·외부 업로드는 보류합니다.
