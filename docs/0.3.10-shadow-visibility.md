# 0.3.10 그림자 표시 수정

0.3.9는 COMPONENT/FRAME/INSTANCE에 clipsContent를 필수로 요구했고 unsupported이면 기본 그림자 영역을 숨겼다. 제공된 JSON은 이 복합 조건에서 제외되었으며 clipsContent 실제 값은 JSON에 없다.

Figma 문서의 clipsContent는 자식이 프레임 경계를 넘어 보이는지 제어한다. CSS box-shadow는 요소 박스에 적용된다. 따라서 clipsContent 자체로 박스 그림자 수치 비교를 배제하지 않는다. 단일 불투명 SOLID fill과 기존 합성/transform 제한 및 Inspect CSS의 유일한 effect 대응을 확인한다. 투명/복합 fill은 알파 형상·자식 합성 불확실성으로 제외한다. 자식의 렌더링 전체나 시각적 일치를 보장하지 않는다.

- https://developers.figma.com/docs/plugins/api/FrameNode/#clipscontent-boolean
- https://developers.figma.com/docs/plugins/api/FrameNode/#getcssasync-promise-key-string-string
- https://www.w3.org/TR/css-backgrounds-3/#box-shadow

기본 그림자 영역을 항상 표시한다. supported는 CSS 비교값 또는 없음, unknown은 미수집, unsupported는 비교 불가 사유를 표시한다. unknown/unsupported에 원본 shadow effects가 있으면 X/Y/Radius/Spread/RGBA/Blend/숨김 여부를 Figma 원본으로 표시한다. Radius를 CSS Blur로 대체하지 않는다. 원본은 JSON의 effects에도 유지한다.

fixtures/component-shadows.json은 사용자가 제공한 노드/효과 값이다. clipsContent는 제공되지 않았으므로 fixture에 추가하지 않았다. 테스트에서 on/off/미정과 합성 제외를 각각 구성한다. CSS blur 10/10/0.5는 합성 테스트 응답이며 실제 Figma Inspect 값 또는 radius 변환 규칙이라고 주장하지 않는다. 실제 Figma 앱 검증은 별도 필요하다.
