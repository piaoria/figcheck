# FigCheck 0.2.1 정확도·UX 변경

## 확인된 원인과 확인하지 못한 부분

보고된 두께의 실제 차이는 약 0.00000001544px입니다. 0.2.0 엔진은 모든 수치에 1e-9를 더해 비교하여 Strict/0 허용오차에서 이 표현 오차를 불일치로 처리했습니다. Normal ±1px에서는 해당 두께가 일치해야 합니다. 사용자가 당시 사용한 모드는 제공되지 않았습니다.

RGBA는 객체/배열 동일성으로 비교하지 않고 네 채널을 수치 비교합니다. 동일한 raw [222,226,230,1]끼리는 기존 엔진도 일치합니다. 반면 Figma의 normalized 채널을 float32로 표현해 255를 곱하면 [222.00000196695328,226.0000017285347,230.00000149011612,1]로 재현됩니다. 웹 [222,226,230,1]과 엄격 비교 시 불일치지만 UI가 셋째 자리로 줄이면 같아 보였습니다. 사용자의 실제 색 raw JSON을 받지 않았으므로 이것이 그 색의 실제 원인이었다고 확정하지 않습니다.

## 보정 원칙

원본 값·RGBA·차이는 유지합니다. px는 CSS px, RGB는 sRGB 0~255, alpha/opacity는 0~1로 비교합니다. 입력을 정수로 반올림하거나 크기에 비례하는 오차를 쓰지 않습니다. 사용자 비교 허용오차와 별도로 px 1e-6, RGB 채널 2e-5, alpha/opacity 1e-7의 고정 절대 numerical epsilon을 적용합니다. fontWeight는 1e-9입니다. 이 범위를 벗어난 차이와 허용오차 경계를 넘는 유의미한 차이는 유지합니다. 이는 렌더링/디자인 정책 차이를 허용하는 기준이 아니라 float32와 CSS 수치 직렬화의 표현 정밀도입니다.

일상 값은 소수 셋째 자리로 읽기 쉽게 표시하고, 0으로 줄어들 작은 비영 값은 유효숫자/과학적 표기로 보여줍니다. 차이에는 RGB/alpha 채널명을 표시합니다. +0px 더 큼이나 0,0,0,0 다름으로 설명하지 않습니다. 결과의 **원본 값 · 정밀도 확인**에서 줄이지 않은 값을 확인할 수 있습니다. unsupported/unknown은 값 0으로 대체하지 않고 점수에서 제외합니다.

너비 282→420과 높이 450.5→588.5의 +138px는 실제 수치 차이로 남습니다. DOM은 transform/zoom 없는 border-box rect, Figma는 local geometry라는 기존 기준을 유지합니다. 사용자 텍스트만으로 padding/border/box-sizing 등 어느 원인이 +138을 만들었는지 알 수 없습니다. 실제 DOM·computed 값·CSS 후보를 확인해야 하며 원인을 꾸며내지 않습니다.

## 사용 흐름

모드 드롭다운을 없앴습니다. 기본 기준은 size/spacing/border/radius ±1px, typography ±0.5px, RGB 각 채널 ±1, alpha·opacity ±0.01이며 fontWeight/fontFamily는 일치해야 합니다. 결과 아래의 항상 보이는 체크박스로 그룹 전체 또는 개별 속성을 포함/제외합니다. 선택은 이 확장의 로컬 저장소에 보관됩니다. 사용자 제외는 미지원과 별도로 표시되고 결과·항목별 점수·분모에서 빠집니다. 전부 해제하면 100%가 아니라 점수 없음입니다. 기존 엔진 preset API는 호환성과 회귀 검증을 위해 남겼습니다.

Figma는 선택→자동 추출→속성 요약·JSON 바로 표시→복사로 진행합니다. 파일 저장은 보조, 새로 추출은 속성만 바꿨을 때 또는 복구할 때 사용합니다. 선택 변경 즉시 이전 JSON과 복사 상태를 비우고 request ID/sequence로 늦은 응답을 무시합니다. Chrome은 붙여넣기 입력으로 시작하고 완료하면 짧은 디자인 요약으로 접습니다. 웹 선택 후 결과가 자동 표시됩니다. 범위가 여러 노드일 때만 Figma 노드 선택 목록이 나타납니다.

차콜 배경과 단색 surface/버튼을 사용합니다. 장식 gradient는 작은 브랜드 표시 하나의 blue→violet, 좌측→우측 두 stop입니다. 큰 gradient 버튼·중복 수치 카드·모드 선택을 제거했습니다. 속성명과 분류에는 별도 줄 또는 간격·문자 구분자가 있습니다. 키보드와 320/360px, 빈 선택·다중 선택·로딩·오류·복사 성공/실패 화면을 확인했습니다.

설치는 [설치·사용 안내](설치-사용.md), 범위는 [검증 안내](검증.md)를 참고하세요. 실제 Figma 호스트와 실제 OS 키→Chrome command 이벤트는 미검증입니다.
