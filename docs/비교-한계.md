# 비교 계약·보안·한계

## 공통 데이터

schemaVersion `1.0`, source `figma`, exportedAt, nodes를 가진 교환 문서입니다. colorProfile은 선택 필드이며 새 export는 항상 기록합니다. 색공간을 기록하지 않는 1.0 JSON은 sRGB로 취급합니다. 별도 JSON Schema가 제공되며 런타임 검증은 파일 1 MiB, 총 노드 256개, 깊이 16, 중복 ID 금지, 문자열 길이, 모든 속성의 status/kind/value, RGBA 범위와 유한 숫자를 추가 검증합니다. unknown/unsupported에는 reason이 필수이며 value를 받지 않습니다. 누락값/0/null을 일치로 대체하지 않습니다. 잘못된 버전/임의 키/구형 스키마는 거부합니다.

플러그인은 단일 선택 노드만 export합니다. nested 문서 import는 수동 노드 선택을 위한 데이터 탐색입니다. ID와 이름으로 DOM을 검색하거나 자동 매칭하지 않습니다. 속성 규약을 모르는 기존 단일 node JSON은 자동 추측 변환하지 않습니다.

## 크기·spacing·border

DOM width/height는 **transform과 zoom 없는 실제 border-box rect의 CSS px**입니다. computed width/height 및 box-sizing 원문도 근거에 보관합니다. 예: content-box width 100 + 좌우 padding 각 10 + 좌우 border 각 2 = 비교 width 124. Figma는 선택 노드의 local width/height를 사용합니다. Figma의 Auto Layout 자동 크기가 현재 구체적인 숫자면 그 스냅샷을 비교합니다. 크기 정책 자체의 동등성을 판정하지 않습니다.

자기 또는 조상 transform/zoom, 분절된 rect, inline/contents, SVG의 size는 제외합니다. Figma 자기/조상 회전·scale, CENTER/OUTSIDE stroke는 size 계약이 달라 제외합니다. 비정상적으로 깊은 DOM 조상(64단계)은 확정하지 않습니다. translation만 있는 Figma local transform은 layout 위치이고 width/height에는 영향을 주지 않습니다. 좌표/위치는 비교 범위 밖입니다.

Figma HORIZONTAL/VERTICAL Auto Layout의 padding을 읽고 primary/counter gap을 row/column으로 매핑합니다. wrap 없는 교차 gap은 unknown, SPACE_BETWEEN은 고정 gap이 아니므로 unsupported입니다. DOM gap은 flex/grid에서만 적용 대상으로 비교합니다. Figma GRID는 MVP에서 미지원입니다.

CSS %, em/rem, calc, auto가 브라우저 computedStyle에서 단일 px로 해결됐다면 **해결된 스냅샷 값**으로 비교합니다. normal/auto/%/calc 등이 문자열에 남아 있으면 unsupported입니다. authored 단위의 일치, responsive 정책, calc 의미를 비교하는 것은 아닙니다. elliptical/복합 radius와 Figma corner smoothing은 제외합니다. radius는 4모서리 각각 단일 px만 지원합니다.

CSS solid border와 Figma rectangular frame/rectangle/component/instance의 단일 SOLID INSIDE stroke를 매핑합니다. vector/text의 stroke, 다중 stroke, gradient, CENTER/OUTSIDE stroke, dotted/dashed 등은 제외합니다. 보이는 border가 없는 경우 width 0은 확인된 실제 값이며 color는 분모에서 제외합니다. stroke 없음과 알 수 없는 stroke는 구분합니다.

## 텍스트·색·opacity

Figma TEXT에 단일 fontName/fontSize/fontWeight를 사용하며 mixed Symbol은 제외합니다. fontWeight는 API의 숫자를 읽고 style 이름에서 추정하지 않습니다. lineHeight/letterSpacing PIXELS는 직접 읽고 PERCENT는 단일 fontSize를 기준으로 px 환산합니다. AUTO line-height 또는 mixed 기준 fontSize는 제외합니다.

CSS font-family는 첫 요청 family와 비교하며 실제로 선택된 fallback/렌더 폰트를 감지하지 않습니다. 자식 요소/생성 텍스트가 있거나 직접 텍스트가 없는 DOM 요소에서는 typography/textColor를 제외합니다. FRAME을 선택해도 자식 텍스트를 대신 읽지 않습니다. 글꼴 종류/변형, 폰트 로딩, shaping/kerning, 실제 픽셀 크기의 같음을 보장하지 않습니다.

색은 sRGB RGB 0~255와 alpha 0~1의 채널별 비교입니다. Figma SOLID paint opacity는 색 alpha이고 node opacity는 별도 속성입니다. gradient/image/다중 paint/paint blend는 제외합니다. Figma DISPLAY_P3 및 LEGACY/알 수 없는 색공간은 색 비교에서 제외합니다. CSS color(display-p3), oklch 등 sRGB rgb/rgba로 해결되지 않은 색도 제외합니다. DOM background-image가 있으면 backgroundColor를 복합 배경으로 제외합니다. RGBA와 요소 자체 opacity를 비교하며 조상 opacity, 배경 합성, mix-blend/filter 또는 실제 화면 픽셀 색은 계산하지 않습니다.

## CSS 원인 근거의 의미

getComputedStyle은 해결된 값을 제공하지만 cascade 승자의 출처를 제공하지 않습니다. FigCheck는 DOM 클래스 및 inline 원문, 접근 가능한 CSSStyleSheet.cssRules에서 selector가 일치하는 규칙을 보여줍니다. 조상 규칙은 상속 **후보**로 따로 표시합니다. 동일 값의 여러 규칙이 있어도 실제 승자를 단정하지 않습니다.

media/supports는 현재 조건을 확인합니다. layer/important 역순, specificity, shorthand/longhand, inheritance, animation/transition, @scope/container, nested selector, import 조건, Shadow DOM/slot의 전체 cascade를 재구현하지 않습니다. 후보의 존재는 적용·승자를 증명하지 않습니다. CSSOM 접근불가/상한 도달은 **부분조회**로 표시하고 규칙이 안 보이면 원인 추적불가로 봅니다. 직접 요소 규칙에 부모에게서 상속되지 않는 속성도 함께 있을 수 있습니다.

cross-origin stylesheet의 SecurityError는 sheet별로 처리합니다. 값이 computedStyle에 반영돼도 규칙의 원문은 읽지 못할 수 있습니다. 현재 문서와 선택 ShadowRoot의 접근 가능한 stylesheet/adopted stylesheet를 보며, 상속 후보 조상 8개, 규칙 2000개, 후보 100개로 제한합니다. 접근 실패가 다른 sheet의 조회를 중단시키지 않습니다. closed shadow root 또는 복잡한 import/scope 조건은 부분조회입니다.

source는 CSSOM이 제공하는 실제 stylesheet href 또는 inline stylesheet 표기입니다. 원본 소스 줄 번호와 source map, 빌드 이전 파일명, authoring Tailwind 클래스를 만들어내지 않습니다. DevTools에서 CSS 원인을 최종 확인해야 합니다.

## 로컬 처리와 입력 안전

확장에 broad permissions/host_permissions/debugger/content scripts가 없습니다. 고정된 collector 함수만 inspectedWindow.eval로 실행하고, JSON·노드 이름·클래스·CSS 데이터는 eval 코드에 삽입하지 않습니다. JSON.parse 후 구조를 검증하며 모든 데이터 UI는 textContent로 렌더합니다. JSON을 HTML 또는 코드로 실행하지 않습니다. inspected page가 API를 변조할 수 있으므로 반환 snapshot의 크기/타입도 검증합니다. 페이지가 자체적으로 거짓 데이터를 반환하는 경우 진위를 보장할 수는 없습니다.

JSON은 extension origin의 localStorage에만 보관하며 JSON 지우기로 삭제합니다. 비교한 DOM 정보는 메모리에만 보관하고 외부로 보내지 않습니다. Figma 네트워크 접근은 none이며 Chrome 확장 CSP connect-src도 none입니다. 백엔드·분석 SDK·원격 폰트/이미지 의존성이 없습니다. 배포 ZIP을 Library에 저장하는 행위는 사용자가 요청한 산출물 저장이며 제품의 분석 데이터 전송과 별개입니다.
