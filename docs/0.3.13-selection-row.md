# 0.3.13 · Figma 선택 행 액션

선택한 노드 정보 오른쪽에 JSON 복사(아이콘+풀라벨)와 파일 저장(아이콘만)을 배치했습니다. 기존 별도 액션 줄은 제거했습니다. 정보 영역 min-width:0, 노드명 단일행 말줄임과 title 전체 이름, 액션 flex-shrink 방지, 복사108px 고정폭, 저장32px를 사용합니다. 저장의 title/aria-label은 디자인 JSON 파일 저장입니다.

선택없음/추출중/오류 비활성화, 복사 완료 체크+2.5초 복귀,160ms 전환,reduced-motion,연속요청 무효화,복사 실패 수동복구 로직은 유지합니다. Figma UI에만 레이아웃을 적용하며 확장에는 릴리스 버전만 갱신했습니다.

npm run verify 및 npm run test:plugin-browser로 검증합니다. 320px에서 긴 이름·버튼 한 행·말줄임·전체이름·키보드 저장 포커스·고정복사폭을 light/dark 각각 검증합니다. 캡처: artifacts/figma-selection-row-light.png 및 figma-selection-row-dark.png. 실제 Figma 호스트는 별도 확인이 필요합니다.
