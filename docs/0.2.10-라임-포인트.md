# FigCheck 0.2.10 라임 포인트

주요 **JSON 복사 / 요소 선택** 버튼과 선택 상태를 강한 라임 `#B8F500`으로 표시합니다. 버튼 글자는 거의 검정인 `#101400`입니다. 라이트·다크 배경은 계속 중립색이며 라임은 포인트에만 사용합니다.

| 상태 | 라이트 | 다크 |
|---|---|---|
| 기본·선택 | #B8F500 | #B8F500 |
| hover | #A8DF00 | #C8FF28 |
| pressed | #97C900 | #A8DF00 |
| 링크·focus | #355000 / #496500 | #B8F500 |
| 속성 아이콘 | #3B5700 | 기존 밝은 중립색 |
| disabled | 중립 배경·회색 글자 | 중립 배경·회색 글자 |

라이트 배경의 링크와 아이콘은 진한 녹색으로 읽기 쉽게 구분합니다. 오류·불일치의 빨간 계열과 일치의 별도 녹색을 유지하며, 상태는 글자로 함께 안내합니다. 키보드 focus는 윤곽선으로 표시하고, disabled에는 라임을 적용하지 않습니다. gradient는 사용하지 않습니다.

Pretendard 로컬 글꼴, 추출·비교 가능한 값 중심 표, 한 단계 자세히 보기, 속성 아이콘, 도움말, HEX/RGB/HSL 표시와 원본 RGBA·JSON·점수는 유지합니다. 이미 고른 라이트/다크 및 색상 표기 설정도 같은 앱별 저장 키를 사용합니다.

## 업데이트

Chrome 확장 화면에서 새로고침을 누르고 DevTools를 닫았다가 다시 여세요. Figma 플러그인을 닫고 같은 dist manifest로 다시 실행하세요. UI와 host 버전이 0.2.10인지 확인합니다. 자세한 순서는 [설치 안내](설치-사용.md)를 참고하세요.

## 검증 범위

두 테마의 primary 기본·hover·pressed 글자 대비, 링크·아이콘 대비, focus 및 중립 disabled 상태를 수치와 실제 Chromium 입력으로 확인합니다. 기존 기능·저장값·좁은 화면 검증도 실행합니다. 실제 Figma 호스트와 OS 전역 단축키는 미검증이며 Figma 이미지는 mock 호스트의 화면입니다. [검증 기록](검증.md)을 참고하세요.
