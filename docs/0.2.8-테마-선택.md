# FigCheck 0.2.8 테마 선택

아이보리는 주요 동작과 선택 강조의 색입니다. 배경은 중립적인 라이트와 다크로 구분합니다. 화면 위의 **라이트 / 다크** 버튼을 누르면 즉시 전환하며 드롭다운이나 자동 모드는 없습니다. 버튼은 현재 테마를 표시하고, 스크린리더에는 다크 테마의 켜짐 여부를 알립니다. Tab으로 이동한 뒤 Enter 또는 Space로 전환합니다.

도움말을 연 상태에서도 도움말 머리말의 같은 버튼을 사용할 수 있습니다. 전환할 때 입력, 추출 결과, JSON 보기, 비교 결과와 열려 있는 분류·상세를 지우지 않습니다. 오류·차이·지원 여부는 문구와 함께 표시하며 색 견본은 디자인/DOM의 원래 색을 유지합니다.

## 처음 열 때와 저장

Figma와 Chrome의 선택은 서로 독립적입니다.

- Figma는 플러그인 ID별 로컬 `clientStorage`에 `light` 또는 `dark`를 저장합니다. 저장값이 없으면 시작할 때 Figma가 전달한 `figma-dark` / `figma-light` 테마를 사용하며, 호스트 테마 정보가 없으면 라이트로 시작합니다. 나중에 Figma 테마가 바뀌어도 이번 창의 선택을 자동으로 바꾸지 않습니다.
- DevTools는 확장 페이지의 `localStorage`에 저장합니다. 저장값이 없으면 시작할 때 DevTools의 `themeName`을 사용하고, 다크가 아니면 라이트로 시작합니다. 새 권한이 필요하지 않습니다.
- 저장값은 두 문자열만 인정합니다. 저장소 접근이 실패하면 비교·추출은 계속 사용할 수 있습니다. 저장 실패 안내가 표시되면 이번 창에만 적용된 것이므로 다음 창에서 다시 선택해야 할 수 있습니다.
- 로컬 데이터 삭제, 확장 삭제 또는 Figma 플러그인 ID 변경 시 선택을 잃을 수 있습니다. 다른 컴퓨터·앱으로 동기화하지 않습니다. **비우기**는 비교용 JSON을 지우며 테마 선택은 유지합니다.

Figma의 비동기 저장은 순서대로 처리하여 마지막 선택이 우선합니다. 늦은 초기 저장값 읽기가 사용자의 새 선택을 덮어쓰지 않습니다. 테마 설정 메시지는 추출 메시지와 분리하여 선택 변경·응답 대기·재시도 상태를 초기화하지 않습니다.

## 색상 역할

라이트는 밝은 회색 배경과 흰 표면, 다크는 중립 charcoal 배경과 구분되는 표면을 사용합니다. 주요 버튼은 아이보리와 진한 글자로 표시하며 라이트에서도 별도 테두리로 구분합니다. 다크의 아이보리는 밝기를 절제합니다. 아이콘, 링크, 텍스트, 포커스, 상태, 주요 동작을 각각의 역할 토큰으로 관리합니다. 그라디언트와 외부 글꼴은 사용하지 않습니다.

## 검증 범위

실제 격리 Chrome 확장/DevTools와 Figma host VM + Chromium UI mock에서 키보드 전환, 재열기·저장 복원, 입력·값·접힘 유지, 열린 도움말, 320px 화면, 대비, 견본 색 유지와 저장 실패 복구를 확인했습니다. 원본 테마별 화면은 `artifacts/figma-theme-light.png`, `figma-theme-dark.png`, `devtools-theme-light.png`, `devtools-theme-dark.png`에 있습니다. 비교 이미지는 원본을 확대·축소·왜곡하지 않고 나란히 배치합니다.

실제 Figma 데스크톱 호스트와 물리적 OS 키 → Chrome command 이벤트는 미검증입니다. Figma 화면은 mock입니다. 설치 후 플러그인 ID와 사용자 환경에서 저장 복원을 확인하세요. [전체 검증 안내](검증.md)를 함께 참고하세요.

공식 API: [Figma clientStorage](https://developers.figma.com/docs/plugins/api/figma-clientStorage/), [Figma 테마 정보](https://developers.figma.com/docs/plugins/css-variables/), [Chrome DevTools panels](https://developer.chrome.com/docs/extensions/reference/api/devtools/panels).
