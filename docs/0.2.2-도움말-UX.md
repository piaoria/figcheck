# FigCheck 0.2.2 도움말·작업 화면

Figma와 DevTools 헤더 우측의 **?**에서 처음 사용, JSON 전달, 단축키, 비교 범위를 확인합니다. Figma의 연결/오류 진단도 도움말 안에 있습니다. 실제 오류 메시지와 새로 추출·다시 복사 등 복구 버튼은 작업 화면에 남습니다. 도움말은 Enter로 열고 Tab/Shift+Tab으로 이동하며 Esc 또는 닫기로 닫습니다. 닫으면 ?로 포커스가 돌아갑니다. 좁은 패널에서는 높이를 제한한 영역 안에서 스크롤합니다. 입력 중 물음표 문자를 전역으로 가로채지 않습니다.

상시 소개 문구, 번호 단계 표시, 선택 방법 설명, 단축키 줄, 제외/오차 설명, 개인정보 반복 문구를 작업 화면에서 제거했습니다. 선택 대기·추출 중·완료·실패와 JSON/DOM 오류는 문맥에 유지합니다. 작업 화면은 작은 헤더, 선택한 source 두 곳, 직접 액션, 값 비교와 포함 체크로 구성합니다. JSON 즉시 표시·복사, 파일 교환·붙여넣기, 단일 비교, 수치 보정은 그대로입니다. CSS 원인 후보와 값 자체의 미지원 이유는 실제 데이터이므로 상세 영역에 남습니다.

## 레퍼런스와 적용

| 공식 자료 | 적용한 패턴 |
|---|---|
| [Chrome DevTools CSS reference](https://developer.chrome.com/docs/devtools/css/reference) | 좁은 액션행, 정렬된 속성/값, 작은 색 견본, 체크박스와 접히는 데이터 상세. 수치에 monospace·tabular digits를 적용하고 표 구분선을 약하게 유지했습니다. |
| [Figma Dev Mode Compare changes](https://help.figma.com/hc/en-us/articles/15023193382935-Compare-changes-in-Dev-Mode), [Guide to Dev Mode](https://help.figma.com/hc/en-us/articles/15023124644247-Guide-to-Dev-Mode-in-Figma) | 선택 레이어 정체성을 값보다 먼저 보여주고 디자인/웹 값을 같은 열 구조로 나란히 배치했습니다. 변경 웹 값과 차이 문자를 강조하며 색만으로 상태를 전달하지 않습니다. |
| [VisBug Keyboard Master List](https://github.com/GoogleChromeLabs/ProjectVisBug/wiki/Keyboard-Master-List) | ? 진입점에서 툴 사용법·키를 확인하는 패턴. 저장소는 archive 상태이며 현행 제품 추천이 아닌 interaction reference로만 사용했습니다. |
| [Pixelay compare designs](https://docs.hypermatic.com/pixelay/compare-designs), [제품 소개](https://www.hypermatic.com/pixelay/) | source pairing과 comparison controls를 분리했습니다. 완료된 입력은 source 요약, JSON 복사는 데이터 바로 아래입니다. overlay 기능은 가져오지 않았습니다. |
| [WAI-ARIA modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) | 이름 있는 modal, 내부 포커스 이동/순환, Esc·닫기, trigger 포커스 복귀를 구현했습니다. |

공식 레퍼런스의 비교 제어 패턴을 적용하고 WAI/DevTools 문서로 접근성·표 동작을 확인했습니다. 전체 UI를 복제하지 않았으며 새 디자인 라이브러리를 추가하지 않았습니다. 행 간격은 FigCheck의 좁은 패널에 맞춘 구현 선택이고 공식 제품의 치수라고 주장하지 않습니다. 차콜 배경·단색 제어·작은 blue→violet 브랜드 accent를 유지했습니다.

실제 Figma 호스트와 OS 키→Chrome commands 이벤트는 미검증입니다. Figma UI 시험은 mock, Chrome은 격리된 실제 unpacked 확장 시험입니다. 자세한 지원 조건은 [비교 속성 목록](지원-속성.md), 시험은 [검증 안내](검증.md)를 확인하세요.
