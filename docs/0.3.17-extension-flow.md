# 0.3.17 · 확장 흐름과 공통 헤더

DevTools 패널 제목은 정확히 FigCheck ⇄입니다.4색 코너 로고 파일은 유지합니다. 양쪽 헤더 왼쪽에 작은 로고+FigCheck·버전,오른쪽에 테마/설정/도움말을 배치하고 푸터 중복브랜드를 제거했습니다. 버전은 기존 릴리스 소스→빌드 경로로 동기화합니다.

확장 화면의 디자인입력→웹요소선택→비교결과를 세 개의 옅은무채색 기능영역으로 구분합니다. 비교점수와 차이표를 미리보기보다 먼저 배치합니다. 요소속성의 영역/색상/타이포그래피는 고정섹션이며 Figma함께보기 토글을 유지합니다. 배경은 최상위 기능영역에만 있고 행별카드/그림자/그라데이션/중첩surface를 추가하지 않습니다. 반복행/섹션divider와 반복미리보기설명을 줄였습니다.

긴 CSS근거는 바깥 한 단계 disclosure를 유지하고 내부 후보/측정정보는 고정하위섹션입니다. 붙여넣기편집/취소,추가정보/돌아가기,설정,미지원/실패/사용자제외/그림자 구분은 유지합니다. 엔진/score/schema 변경없음. 플러그인은 헤더이동외 기존0.3.16 섹션UI를 유지합니다.

검증: npm run verify, node scripts/brand-review.mjs, npm run test:browser, npm run test:picker. 실제Edge확장과Figma모의호스트UI를 사용하며 실제Figma호스트/물리OS단축키는 별도 확인대상입니다. 캡처 artifacts/devtools-theme-light-narrow.png / devtools-theme-dark-narrow.png 및 figma-theme-*-narrow.png.

## 빈 상태 안내
- 플러그인: 선택 없음과 여러 개 선택은 자동 추출을 안내하고 데이터 없는 내보내기·재추출 버튼을 숨깁니다. 오류·시간 초과의 재시도는 유지합니다. 미지원 속성은 다른 요소 선택과 추가 정보로 안내합니다.
- 확장: 두 입력 없음 / 디자인만 없음 / 웹 요소만 없음을 구분합니다. 중복 CTA와 빈 미리보기는 제거하며 상단 입력 및 요소 선택, 취소·복구 경로는 유지합니다.

## 단계 헤더 통일
디자인 입력·웹 요소 선택·비교 결과는 공통 step-section / step-header 규칙을 사용합니다. ①·②·③ 번호와 14px/20px 제목, 8px 본문 간격, 같은 배경·패딩·모서리를 적용합니다. 비교 결과의 체크 아이콘과 별도 번호 표기는 제거하고 빈 상태의 추가 패딩을 없앴습니다. ③ 제목은 추가 정보에서도 유지하며 점수·필터·표의 기능과 값은 바꾸지 않습니다. 단계별 조작은 헤더 아래 본문에 둡니다.

## 입력 안내 압축
디자인 이름과 상태, 웹 대상과 크기·안내를 flex-wrap 행으로 묶었습니다. 붙여넣기 label과 안내도 가로 공간을 공유하고, 선택·새로 확인 버튼과 선택 상태는 한 동작 행에 둡니다. 중복 JSON 대기/선택 확인 문구를 줄였으며 긴 설명·오류는 자연스럽게 줄바꿈합니다. 비교 결과의 값·표·점수와 단계 헤더는 유지합니다.

## 비교 속성 설정
크기·여백과 간격·글꼴·색상·테두리와 모서리·투명도·그림자를 카테고리 카드로 구분합니다. 넓은 모달은 2열 선택 그리드, 좁은 모달은 1열이며 추가 접기는 없습니다. 기존 카테고리 전체/부분 선택과 즉시 저장을 유지하고 전체 선택/해제는 그림자까지 함께 적용합니다. 전체 해제는 비교 점수를 만들지 않습니다. 무채색 모달과 선택/hover/focus, 고정 닫기 헤더, 단일 스크롤을 사용합니다. 설정 바깥에서 누르고 떼면 닫히며 원래 버튼으로 초점이 돌아갑니다.

## 결과 표 정렬
차이만·전체 비교값 모두 분류를 tbody 그룹 제목에 한 번 표시합니다. 속성별 반복 분류명을 제거하고 실제 방향·속성 이름은 유지합니다. 행/열/그룹 header 연결로 읽기 문맥을 제공합니다. 값과 열 제목은 오른쪽 정렬, 속성은 왼쪽 정렬이며 숫자는 tabular 표시를 유지합니다. 좁은 화면에서 긴 색상·글꼴은 디자인/웹 두 칸 아래 차이를 놓습니다. 그림자는 동등한 두 열과 긴 값 줄바꿈을 사용하며 값·점수는 변경하지 않습니다.

## 설정 선택 계층
카테고리 전체 선택은 강조한 부모 헤더, 개별 속성은 들여쓴 자식 목록으로 구분합니다. 여백은 내부 여백/요소 사이 간격, 테두리는 두께/색상/모서리 반경 소제목 아래 정렬합니다. 소제목에는 별도 체크박스·접기를 추가하지 않습니다. 부모는 자식의 전체/일부/없음 상태를 반영하며 기존 즉시 저장과 전체 선택/해제 동작을 유지합니다. 그림자는 독립 선택 항목입니다.
