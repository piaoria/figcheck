# 0.3.15 불필요한 구분선 제거

Figma 플러그인에만 적용합니다. 반복 속성 섹션·표 머리/본문 행(마지막 행 포함)·그림자 행·영역도식 바깥 카드/들여쓰기 선·푸터 선을 제거했습니다. 섹션은 제목/아이콘/16px 간격으로 구분하며 기존20px 간격도 줄였습니다. 영역도식은8px 들여쓰기로 하위영역임을 표시합니다.

유지한 선: 전역 설정 툴바와 선택/결과를 구분하는 header 경계, 진단 정보 경계, 실제 Box Border/Padding/Radius 도식, 색상 swatch/checkerboard, 버튼/입력 경계 및 키보드 focus. 데이터 시각화와 포커스 선을 장식divider로 취급하지 않습니다.

한줄 액션·복사피드백·그림자 원본/미지원표시·추출값·스키마·고정섹션을 유지합니다. 공유CSS는 변경하지 않았습니다.

npm run verify 및 npm run test:browser로 검증하며 양테마에서 장식선0/실제박스와swatch선유지/320px넘침/키보드/복사복구를 확인합니다. 최종 캡처 artifacts/figma-theme-light-narrow.png 및 figma-theme-dark-narrow.png. 실제 Figma 호스트는 별도 확인이 필요합니다.
