# 0.3.20 — 웹 탐색 우선, 선택적 Figma 비교

첫 화면은 웹 요소 선택입니다. JSON 없이도 영역 구조·색상·타이포그래피를 표시하고, 미입력 JSON을 오류나 미완료 단계로 안내하지 않습니다. Figma 비교 추가에서 JSON을 붙여넣거나 파일로 가져오면 현재 Web 선택을 유지해 비교합니다. 기존 Figma 추출·가져오기·비교·점수 로직은 유지합니다.

페이지의 고정 A 정보에 기존 Border > Padding 중첩과 네 모서리 Radius, 공통 속성 아이콘을 작은 도식으로 표시합니다. 중심은 렌더링 경계 크기(CSS px), 하단은 computed CSS width/height와 box-sizing입니다. 변환된 렌더링 크기를 CSS 너비 또는 Figma local 크기와 혼동하지 않도록 구분합니다. 단일 px로 확정되지 않는 radius 등은 N/A입니다. 도식은 비례 축척이 아니며 content를 임의 역산하지 않습니다.

기본 정보 위치는 좌상단이며 선택 요소를 가리는 경우 다른 모서리로 이동합니다. 짧은 뷰포트에서는 도식을 축소합니다. Alt로 B와 거리를 보는 동안에는 도식을 잠시 접어 측정선을 우선하며, Alt 해제 후 A 도식이 돌아옵니다. 오버레이 자체는 선택·수집·거리 대상에서 제외합니다.

‘값 새로 확인’ 버튼을 제거했습니다. 패널이 활성이고 선택 요소가 있을 때 기존 하나의 갱신 스케줄에서 750ms마다 computed 값·렌더 크기·제한된 조상 상태를 확인합니다. 실제 값이 달라진 경우에만 CSS 후보를 포함해 다시 수집합니다. 중복 진행을 막고 선택 세대로 오래된 응답을 버립니다. 비활성 패널·선택 없음·삭제된 노드는 값 확인을 중단합니다. 페이지 오버레이는 기존 갱신 경로를 사용하며 도식 DOM은 값이 달라질 때만 재생성합니다. Esc는 오버레이를 종료하고 이미 확정한 선택/비교 값은 유지합니다.

자동 갱신은 모든 애니메이션 프레임을 기록하지 않으며 패널 반영에는 보통 최대 약 750ms와 평가 시간이 필요합니다. 브라우저의 백그라운드 스케줄 제한도 적용됩니다. computed 값이 동일한 상태에서 CSS 규칙의 출처만 바뀐 경우 후보 근거는 다시 선택하기 전까지 갱신되지 않을 수 있습니다. 오버레이와 패널은 동일 기준 A를 사용하지만 매 프레임 동기화하는 방식은 아닙니다.

실제 Edge 확장에서 JSON 없는 탐색, 자동 CSS/크기 변경, 이후 JSON 가져오기, 고정 A를 유지한 Alt B 탐색, 제거/빠른 재선택, 작은 화면, 기존 선택·비교 회귀를 검사합니다. Figma UI 검증은 모의 호스트이며 실제 앱/물리 OS 키 검증과 구분합니다. README 최종 정리·커밋·푸시·외부 업로드는 계속 보류합니다.
