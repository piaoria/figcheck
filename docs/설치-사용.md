# FigCheck 0.3.7 설치·사용

빌드된 파일이 포함되어 있어 사용만 할 때는 Node.js가 필요 없습니다. 아래 경로는 `%USERPROFILE%\Desktop\figcheck` 기준입니다. ZIP을 다른 곳에 풀면 그 위치를 사용하세요.

## Figma

1. Figma 데스크톱 앱에서 디자인 파일을 엽니다.
2. Plugins → Development → Import plugin from manifest에서 `apps\figma-plugin\dist\manifest.json`을 선택합니다.
3. 노드 하나를 선택하고 개발 플러그인 **FigCheck 0.3.7 (local)**을 실행합니다.
4. 선택 시 추출된 속성 표가 바로 나타납니다. 추출 완료 상태에서 **JSON 복사**를 누릅니다. **파일 저장**도 지원합니다.

기존 버전이 있으면 플러그인을 닫고 위 manifest를 다시 가져와 실행합니다. 화면 버전과 연결 상태의 UI/host 빌드가 모두 0.3.7인지 확인합니다. 외부 `apps\figma-plugin\manifest.json`도 dist 파일을 가리키는 유효한 manifest입니다. 둘은 같은 플러그인이므로 하나만 가져오세요. API 1.0.0은 앱 버전이 아닙니다.

Figma가 발급된 플러그인 ID를 요구하면 Development → New plugin에서 발급한 manifest의 id만 FigCheck manifest의 id에 넣으세요. 공개 게시할 필요는 없습니다. 다시 빌드할 때 외부 manifest의 id가 dist로 복사됩니다.

선택 변경은 자동 추출됩니다. 속성만 수정한 경우 **새로 추출**을 사용합니다. 선택 없음·다중 선택·추출 중에는 이전 JSON을 복사하거나 내보낼 수 없습니다. JSON 원문은 JSON 보기에서 확인합니다. 복사가 차단되면 그 영역에 **다시 복사**가 나타납니다. 버튼 재시도 또는 Ctrl+C로 직접 복사하세요. 성공하지 않은 복사를 성공으로 표시하지 않습니다.

## Chrome

1. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**합니다.
2. `%USERPROFILE%\Desktop\figcheck\apps\chrome-extension\dist` 폴더를 선택합니다. Chrome 140 이상을 대상으로 합니다.
3. 기존 설치를 업데이트하면 확장의 **새로고침**을 누르고, 열려 있는 DevTools를 닫았다 다시 엽니다.
4. 일반 웹페이지에서 F12 → **FigCheck** 탭을 엽니다. 탭이 숨겨져 있으면 `»` 메뉴를 확인하세요.
5. 처음부터 보이는 입력란에 JSON을 붙여넣고 가져옵니다. 파일 가져오기도 같은 검증을 사용합니다. nested JSON이면 비교할 Figma 노드를 직접 선택합니다.
6. **요소 선택**을 누르고 페이지에서 DOM 하나를 클릭합니다. Elements에서 직접 선택한 `$0`도 사용할 수 있습니다.
7. 차이·일치율·확인 불가 이유를 확인합니다. 값은 웹 − 디자인 방향입니다. 결과의 차이만/전체 비교값 버튼으로 표 범위를 바꿉니다. 전체 비교값은 포함한 항목 중 양쪽 값이 비교 가능한 행만 보여줍니다. 미지원·값 미확인·값 오류·사용자 제외와 원본 정밀도는 자세히 보기에서, CSS 후보는 별도 근거 영역에서 확인합니다. 톱니바퀴 설정 안의 체크박스로 비교할 항목을 선택합니다. 그룹 전체/개별 속성을 지원하며 체크 해제는 사용자 제외로 집계합니다. 모두 해제하면 점수 대신 비교 가능한 속성이 없음을 표시합니다. Strict/Normal/Custom 모드 드롭다운은 없습니다.

DevTools가 열려 있으면 페이지에 포커스를 둔 **Ctrl+Shift+X**로 선택 모드를 켜거나 끌 수 있습니다. 다른 DevTools 탭에서도 선택이 시작됩니다. 선택 후 결과는 FigCheck 탭에서 확인하세요. Chrome이 이 명령에서 FigCheck 탭을 자동으로 활성화하는 것을 제한합니다. DevTools가 닫혀 있으면 툴바에 **F12** 안내 배지가 표시됩니다. 키 충돌은 `chrome://extensions/shortcuts`에서 직접 확인할 수 있습니다. Esc는 선택을 취소합니다.

JSON은 확장 자체의 로컬 저장소에 남으며 **비우기**로 삭제합니다. DOM 스냅샷은 메모리에만 있습니다. 페이지 이동·선택된 DOM 제거·새 선택 시 이전 DOM을 계속 유효하게 표시하지 않습니다. 새로고침 후 Elements에서 다시 선택하세요. 잘못된 붙여넣기는 입력란에 오류를 표시하고 기존 디자인을 유지합니다. 잘못된 파일도 기존 디자인을 유지하고 오류를 표시합니다. 취소는 붙여넣기 초안만 비우고 닫습니다.

## 샘플로 확인

`fixtures/sample.json`을 가져오고 로컬 fixture의 `#card`를 선택합니다. `fixtures/sample-nested.json`은 수동 노드 선택 예제이며 자동 매칭이 아닙니다. 로컬 HTTP 페이지가 필요하면 저장소에서 `npm ci` 후 `npm run fixture`를 실행하고 http://127.0.0.1:4173 을 엽니다. Windows 실행 안내는 README를 참고하세요.

## 개인정보·범위

백엔드·DB·로그인·분석 데이터 외부 전송이 없습니다. Figma networkAccess는 none, Chrome connect-src는 none입니다. Chrome은 commands용 background worker만 사용하며 permissions·host_permissions·content script·chrome.debugger 권한은 없습니다. 사용자가 직접 로드해야 합니다. 웹스토어·Figma Community에 게시하지 않았습니다.

미지원 값은 이유와 함께 점수에서 제외합니다. gradient/mixed/normal/미해결 auto·percent·calc, transform 등 자세한 판정은 [비교·한계](비교-한계.md)를 읽어주세요. CSS 규칙은 후보이며 실제 cascade 승자가 아닙니다. 실제 호스트 시험 범위는 [검증 안내](검증.md)에 구분되어 있습니다.

[정밀도 보정과 0.2.1 변경 안내](0.2.1-정확도-UX.md)에서 자동 비교 기준과 재현 범위를 확인하세요.

[0.2.3 속성 표·JSON 보기와 이동 진단](0.2.3-속성표-이동진단.md)을 참고하세요.

0.2.8에서는 아이보리를 주요 동작 색으로 사용하고 **라이트 / 다크** 버튼으로 배경 테마를 고릅니다. 앱별 로컬 저장값이 우선이며, 없으면 처음 열 때 호스트 테마를 사용합니다. [테마 선택과 저장 안내](0.2.8-테마-선택.md)를 참고하세요.

## 글꼴·추가 정보·색상 표기

Pretendard가 설치되어 있지 않아도 포함된 로컬 글꼴을 사용합니다. Figma 기본 표는 추출 가능한 값만, DevTools 기본 표는 실제 비교 가능한 값만 표시합니다. **자세히 보기**와 **돌아가기**로 빠진 값의 이유를 한 단계에서 확인합니다. 모든 값이 확인 불가이면 빈 표 대신 다음 행동을 안내합니다. JSON 복사·파일 저장에는 미지원 이유까지 원래대로 포함됩니다.

헤더의 **톱니바퀴 설정 → 색상 표기**에서 HEX / RGB / HSL을 고릅니다. 앱별로 로컬 저장하며, 표기만 바뀌고 원본 RGBA·일치율·차이·JSON은 변하지 않습니다. 반올림과 투명도 표시는 [0.2.9 안내](0.2.9-글꼴-기본값-색상.md)에 설명합니다.


0.2.11은 **차가운 무채색 테마**입니다. 라이트는 charcoal 버튼과 흰 글자, 다크는 offwhite 버튼과 검정 글자로 주요 동작을 강조합니다. 실제 비교 색상 견본과 로컬 저장 설정은 유지합니다. [테마 상태별 안내](0.2.11-무채색-테마.md)를 참고하세요.

0.3.3는 헤더의 **해/달 아이콘**으로 테마를 바꾸고 **톱니바퀴 설정**에서 색상 표기 및 DevTools의 비교 속성 포함을 조정합니다. 메인 입력과 결과는 유지합니다. [아이콘·설정 안내](0.2.12-아이콘-설정.md)를 참고하세요.


0.3.3에서는 **구조·색상·폰트 정보**를 펼쳐 기본 Web 보기와 Figma 함께 보기를 전환합니다. 좁은 패널은 위아래 배치이며, 항목을 누르면 표나 제외 이유로 이동합니다. 폰트는 메타데이터만 표시합니다. [시각 비교 사용법과 정확한 범위](0.3.3-시각-비교.md)를 확인하세요.



0.3.4: JSON 복사 성공은 복사 버튼의 **복사 완료** 문구로 2.5초 동안 표시한 뒤 **JSON 복사**로 돌아옵니다. JSON 아래 성공 안내는 표시하지 않습니다. 반복 복사는 마지막 성공부터 시간을 계산하고, 선택 변경·닫기는 안내를 초기화합니다. 실제 실패의 수동 복사 안내는 유지합니다.


0.3.5 색상 정렬·분류 개수 안내: [시각 비교](0.3.5-시각-비교.md). 390px·320px, 라이트·다크, 1색·2색, 긴 alpha·투명 색상과 HEX/RGB/HSL을 빌드 UI의 mock에서 검증했습니다. 실제 Figma 호스트 시험과 구분합니다.


0.3.6: [구조 펼침·개수 제거·복사 전환 안내](0.3.6-시각-비교.md). 기본 펼침과 직접 접힘 보존, 모든 대분류 개수 제거, 실제 Web Animation API 전환, reduced-motion의 전환 생략, 반복 복사와 2.5초 복귀·선택 변경·닫기를 mock UI에서 검증합니다. 실제 Figma 호스트와 물리 OS 단축키 시험은 별개입니다.


0.3.7 [액션 아이콘·푸터 안내](0.3.7-시각-비교.md). 두 테마·좁은 패널의 아이콘 크기/간격/숨김 접근성·텍스트/툴팁, 헤더 브랜드 제거·일반 흐름 푸터, 실제 복사/check 전환·키보드·focus·reduced-motion을 검증합니다. 실제 Figma 호스트와 물리 OS 단축키 전달은 미검증입니다.
