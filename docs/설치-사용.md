# FigCheck 설치·사용

현재 사용 흐름과 지원 범위는 [README](../README.md)를 기준으로 합니다. 아래 경로는 저장소 루트 기준이며, 실행용 빌드가 포함되어 있어 사용만 할 때는 Node.js가 필요 없습니다.

## Chrome

1. Chrome 140 이상에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램 로드**에서 `apps/chrome-extension/dist` 폴더를 선택합니다.
3. 일반 웹페이지의 DevTools에서 **FigCheck ⇄** 탭을 엽니다. 좁은 창에서는 더보기 메뉴를 확인하세요.
4. **요소 선택**으로 웹 요소를 선택합니다. JSON 없이 구조·색상·글꼴을 확인할 수 있습니다.
5. 필요한 경우 **Figma 비교 추가**에서 JSON을 붙여넣거나 하단 비교 영역에서 파일을 가져옵니다.

업데이트 후 확장 관리 화면에서 새로고침하고 기존 DevTools를 닫았다가 다시 여세요. 헤더 버전은 0.3.23입니다. 브라우저 내부 페이지 등 수집이 제한되는 페이지에서는 일반 웹페이지로 이동합니다.

## Figma

1. Figma 데스크톱 앱의 Plugins → Development → Import plugin from manifest에서 `apps/figma-plugin/dist/manifest.json`을 선택합니다.
2. 노드 하나를 선택하고 **FigCheck 0.3.23 (local)**을 실행합니다.
3. 추출된 속성을 확인한 뒤 **JSON 복사** 또는 **파일 저장**으로 전달합니다.

manifest의 `code.js`와 `ui.html`은 같은 dist 폴더에 있어야 합니다. 바깥쪽 `apps/figma-plugin/manifest.json`도 dist를 가리키지만 설치에는 dist manifest를 권장합니다. 같은 플러그인을 중복 등록하지 마세요. Figma가 발급 ID를 요구하면 Development → New plugin에서 발급받은 ID를 사용합니다. 다시 빌드할 경우 바깥쪽 manifest의 ID가 dist로 복사됩니다.

업데이트 후 실행 중인 플러그인을 종료하고 다시 여세요. 선택 변경은 자동 추출합니다. 같은 노드의 속성을 수정했다면 플러그인의 다시 추출을 사용합니다. JSON 복사가 차단되면 표시되는 수동 복사 안내를 따릅니다. [연결 오류](Figma-연결-오류.md)

## 저장과 검증 범위

가져온 디자인과 UI 설정은 로컬에 저장됩니다. **지우기**는 저장된 디자인을 제거하며 DOM 스냅샷은 메모리에서만 유지합니다. 잘못된 파일/붙여넣기는 기존 디자인을 유지합니다. 취소는 입력 초안만 버립니다.

실제 Figma 앱 설치·실행과 물리적 OS 단축키는 자동 시험한 범위가 아닙니다. 실제 확장 브라우저 시험과 Figma 모의 호스트 시험을 구분합니다. [검증 범위](검증.md)
