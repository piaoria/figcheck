# 0.2.5 속성 아이콘

Figma와 Chrome 속성 표에 같은 16px 라인 아이콘을 추가했습니다. 기존 한국어 속성 이름과 값은 그대로 표시하며, 아이콘은 방향과 속성 종류를 빠르게 구분하는 보조 정보입니다. 그룹 제목과 버튼에 장식용 아이콘을 추가하지 않았습니다.

| 속성 | 아이콘의 의미 |
|---|---|
| 너비 / 높이 | 가로 / 세로 치수선 |
| 위 / 우측 / 아래 / 좌측 내부 여백 | 바깥 사각형과 내부 사각형 사이의 해당 방향 간격 |
| 행 / 열 사이 간격 | 위아래 행 사이 / 좌우 열 사이 간격 |
| 테두리 4면의 두께와 색 | 사각형에서 해당 변만 진하게 표시 |
| 모서리 4개 | 좌측 위, 우측 위, 우측 아래, 좌측 아래의 해당 모서리를 둥글게 표시 |
| 글꼴 / 글자 크기 / 굵기 / 줄 높이 / 글자 간격 | 글자 형태, 크기선, B 형태, 줄 간 치수, 글자 간 치수 |
| 글자 색 / 배경 색 / 투명도 | 밑줄 있는 글자, 채워진 사각형, 반투명 원 |

## 참고한 공식 자료

[Figma 개별 모서리와 radius 안내](https://help.figma.com/hc/en-us/articles/360050986854-Adjust-corner-radius-and-smoothing)의 개별 모서리 필드와 [stroke 속성 안내](https://help.figma.com/hc/en-us/articles/360049283914-Apply-and-adjust-stroke-properties)의 개별 변 표현을 참고했습니다. 아이콘은 FigCheck에서 직접 작성한 기본 기하 SVG입니다. Figma 브랜드 자산 파일을 가져오거나 새 아이콘 패키지를 설치하지 않았습니다.

## 사용과 검증

표의 아이콘을 클릭할 필요는 없습니다. 복사, 파일 저장, JSON 보기, 전체 속성/차이만 보기, 포함 항목 체크와 도움말은 이전과 같습니다. 아이콘은 색상에 관계없이 형태로 방향을 나타냅니다. 기본 색상은 중립 회색이며 실제 추출 색상칩은 별도로 유지합니다.

각 아이콘은 `aria-hidden`으로 숨기고 보이는 한국어 레이블을 유지해 스크린리더가 같은 속성 이름을 두 번 읽지 않도록 했습니다. SVG에는 외부 이미지, 링크, 스크립트가 없으며 import한 JSON을 아이콘 마크업으로 실행하지 않습니다.

실제 브라우저에 렌더링한 SVG의 좌표를 검사해 테두리 4면, 모서리 4개, padding 4방향, 행/열 간격과 너비/높이 방향을 확인했습니다. 결과는 `artifacts/figma-icons.json`, `devtools-icons.json`에 기록했습니다. 양쪽 전체 표의 실제 캡처로 4면과 4모서리를 검토하고 Figma 320px, Chrome 360px의 한글 줄바꿈과 가로 넘침도 검사했습니다.

Chrome 화면은 격리 프로필에 확장을 로드한 실제 DevTools입니다. Figma 화면과 추출 시험은 mock이며 실제 Figma 호스트는 미검증입니다. 물리적 OS 단축키 시험도 미검증 상태입니다. 비교 엔진, 허용오차, JSON schemaVersion 1.0, 최소 권한과 로컬 데이터 교환 범위는 유지했습니다.
