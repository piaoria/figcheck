# 현재 비교 속성과 조건 — 0.2.3

코드의 `packages/core/src/index.ts` categories/keys, `apps/figma-plugin/src/extract.ts`, `apps/chrome-extension/src/normalize.ts`, `collect.ts`를 확인한 목록입니다. 28개 항목 모두가 매번 supported라는 뜻은 아닙니다. 양쪽 값을 해석할 수 있고 사용자가 포함한 속성만 점수에 들어갑니다.

| 범주·수 | 정확한 key | 지원 조건 |
|---|---|---|
| 크기 2 | width, height | Figma local width/height. 자기/조상 회전·scale·skew 또는 CENTER/OUTSIDE stroke 제외. DOM은 한 border-box rect이며 SVG·inline·contents·비렌더·다중 rect·자기/조상 transform/zoom·조상 검사 64단계 초과 제외. DOM의 translation도 제외, Figma의 순수 translation은 local size를 바꾸지 않으므로 허용. |
| Padding 4 | paddingTop, paddingRight, paddingBottom, paddingLeft | Figma HORIZONTAL/VERTICAL Auto Layout만. DOM computed px로 해석된 값. margin·위치 좌표는 없음. |
| Gap 2 | rowGap, columnGap | Figma layout 축에 따라 itemSpacing 대응, WRAP이면 counterAxisSpacing 대응. SPACE_BETWEEN 제외, 비-wrap 교차 gap은 unknown. Figma GRID 미지원. DOM flex/inline-flex/grid/inline-grid에서 px로 해결된 gap만. |
| 글꼴 5 | fontFamily, fontSize, fontWeight, lineHeight, letterSpacing | Figma TEXT만, mixed 제외, numeric weight, lineHeight/letterSpacing PIXELS 또는 단일 fontSize 기반 PERCENT. AUTO lineHeight 제외. DOM은 직접 텍스트가 있고 자식 요소·가상 텍스트가 없어야 함. family는 첫 요청 family이며 실제 fallback 폰트 검증 아님. CSS normal/미해결 단위 제외. |
| 색 2 | textColor, backgroundColor | Figma sRGB의 한 visible SOLID paint와 NORMAL blend만. mixed/gradient/image/복합/P3 등 제외. textColor는 TEXT만. TEXT background는 transparent. DOM은 sRGB rgb/rgba/transparent만; background-image가 있으면 배경색 제외. textColor에는 위 텍스트 조건도 적용. |
| Border 두께 4 | borderTopWidth, borderRightWidth, borderBottomWidth, borderLeftWidth | Figma visible stroke 없음은 확인된 0. 그 외 FRAME/RECTANGLE/COMPONENT/INSTANCE/COMPONENT_SET의 하나 SOLID INSIDE stroke. DOM은 px 값, visible non-solid border 제외. |
| Border 색 4 | borderTopColor, borderRightColor, borderBottomColor, borderLeftColor | 위 Figma stroke/색 조건. visible stroke/border가 없으면 color는 unknown으로 점수 제외. DOM solid border의 sRGB 색만. |
| Radius 4 | radiusTopLeft, radiusTopRight, radiusBottomRight, radiusBottomLeft | Figma 숫자 corner별 radius 또는 단일 radius, cornerSmoothing >0 제외. DOM 단일 px 반경만, elliptical/복합/미해결 단위 제외. |
| Opacity 1 | opacity | 노드/요소 자체의 0~1 numeric opacity. 부모 누적 opacity나 paint alpha 합성 결과와 다름. |

%, em/rem, calc, auto가 브라우저 computedStyle에서 px로 해결되면 해석된 값만 비교합니다. unresolved 문자열은 제외합니다. authored 반응형 정책이나 최종 화면 픽셀을 검증하는 도구가 아닙니다.

사용자가 Figma 한 노드와 DOM 한 요소를 직접 고릅니다. Figma FRAME의 자식 텍스트를 대신 비교하지 않고 하위 전체를 펼쳐 분석하지 않습니다. nested JSON은 비교할 노드를 수동으로 고르는 입력 지원입니다. blur/filter, 일반 effects, 이미지, 좌표, z-index, 전체 화면 레이아웃, 자동 매칭은 속성 목록에 없습니다. 일반 외부/내부 박스 그림자는 아래의 별도 조건으로 비교합니다. 회전/transform 등은 비교 조건 확인용이며 별도 비교 속성이 아닙니다.

## 코드와 안내의 주의점

Figma extractor는 현재 `dashPattern`을 검사하지 않습니다. 따라서 Figma dashed stroke가 항상 unsupported라는 보장은 없습니다. DOM dotted/dashed는 제외합니다. 한 SOLID INSIDE Figma stroke에 dashPattern이 있는 경우 solid로 읽힐 수 있어 점수만으로 dash 모양 일치까지 판단하지 마세요. 이는 이번 도움말 패치에서 엔진 동작을 변경하지 않고 확인된 한계로 명시했습니다.

CSS 원인 근거는 rect/computed 값·class/inline·접근 가능한 CSSOM matched-rule 후보입니다. cascade 승자, source line/source map/Tailwind 원인을 확정하지 않습니다. 교차 출처 SecurityError·inheritance/shorthand/media/layer/important 등은 한계와 후보로 표시합니다.

전용 picker는 최상위 HTML 요소에 제한됩니다. Elements $0로 비-HTML 요소를 넘기면 collector는 geometry를 미지원으로 표시하며 computed 값 중 해석 가능한 일부 속성은 남을 수 있습니다. 비-HTML 전체 지원을 의미하지 않습니다.


## 박스 그림자

기본 28개 속성과 별도로 선택적 shadows 버전 1 데이터를 비교합니다. Figma NORMAL 외부/내부 효과와 getCSSAsync의 box-shadow 대응이 확인된 경우에만 지원하며, 여러 겹의 순서를 유지해 추가·누락을 구분합니다. 미수집·미지원은 none이나 0이 아닙니다. blur/filter, 비정상 blend, 모호한 raw effect 대응은 제외합니다. 원본 effect.radius를 CSS blur로 추정하지 않습니다. 자세한 조건은 [그림자 지원 범위](0.3.9-box-shadows.md)와 [근거 보존](0.3.10-shadow-visibility.md)을 참고하세요.
