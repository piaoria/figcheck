# 0.3.21 — Alt는 거리 측정, 휠은 네이티브 스크롤

Alt+휠 뎁스 선택을 제거했습니다. 요소 선택 중의 뎁스 탐색은 ↑/↓로만 수행하고, 휠 이벤트를 가로채거나 취소하지 않습니다. Alt+휠도 브라우저의 페이지/스크롤 컨테이너에 전달합니다. Ctrl 확대와 Shift 스크롤 역시 가로채지 않습니다.

일반 HTML 위에서는 선택 오버레이가 휠의 실제 대상을 덮지 않습니다. 클릭/Enter 선택과 클릭 차단은 기존 캡처 이벤트를 유지합니다. iframe 내부는 기존 미지원 경계로 차단하며 iframe 내부 탐색·스크롤 동작까지 지원하는 것은 아닙니다.

고정 A의 Alt 거리 측정 중 페이지를 스크롤하면 동일한 화면 좌표 아래의 B를 다시 찾습니다. A와 비교 수집 시퀀스는 바뀌지 않습니다. 관련 현재 도움말과 선택 안내도 ↑/↓ 및 휠 스크롤 기준으로 갱신했습니다. 이전 버전 문서는 변경 이력으로 보존합니다.

정보 박스의 장식용 디바이더와 맨 아래 CSS 크기/box-sizing 및 중첩 도식 부연설명을 제거했습니다. Border/Padding 경계, Radius 아이콘, 렌더 경계의 CSS px 단위, 실제 N/A와 오류 안내는 유지합니다.

실제 Edge에서 선택 중 Alt 휠, 내부 스크롤 영역, 고정 후 Alt 스크롤에 따른 B 교체, ↑/↓, 반복 시작/종료, Ctrl/Shift 이벤트 비차단과 기존 JSON 없는 탐색·자동 갱신·비교를 검증합니다. 물리적 OS 키와 실제 Figma 앱의 기존 미검증 범위는 그대로입니다. README 최종 정리·커밋·푸시·외부 업로드는 보류합니다.
