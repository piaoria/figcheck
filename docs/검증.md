# 검증 범위

0.3.23의 기준 명령은 `npm run verify`, `npm run test:picker`, `npm run test:browser`입니다. 보고서와 화면 캡처는 로컬 `artifacts/`에 생성되며 Git에 올리지 않습니다.

| 검증 | 로컬 통과 범위 |
|---|---|
| 타입·린트·빌드 | `npm run verify` |
| 핵심·adapter·host·commands | 62개 테스트 |
| 실제 확장 선택·거리·스크롤 | 23개 체크 |
| 실제 DevTools 통합 | 118개 체크 |
| Figma host VM + 브라우저 UI | 65개 체크 |
| 실제 Figma 앱 호스트 | 미검증 |
| 물리적 Windows Alt/OS 메뉴 | 미검증 |

로컬 검증은 Node.js 24와 격리된 Edge 154 프로필에서 수행했습니다. 사용자의 전역 확장 설치나 브라우저 설정은 바꾸지 않습니다. 다른 환경에서는 설치된 Chromium 또는 `FIGCHECK_BROWSER_PATH`로 지정한 호환 브라우저를 사용합니다. 이 수치는 위 명령의 현재 로컬 결과이며 CI 성공을 뜻하지 않습니다. 현재 저장소에는 GitHub Actions 워크플로가 등록되어 있지 않습니다.

## 실제 확장·DevTools

빌드된 MV3 확장을 로드해 JSON 없는 탐색, 자동 값 변경 반영, 제거/빠른 재선택, 이후 JSON 가져오기, 미지원/제외 처리, 비교 정확도, 320/640/1000px 레이아웃과 키보드 조작을 검사합니다. 실제 commands 등록과 worker→DevTools 전달도 확인합니다. 물리 OS 키가 브라우저 accelerator를 거쳐 commands 이벤트를 만드는 과정은 별도 미검증입니다.

선택 시험은 ↑/↓, 클릭/Enter, 반복 시작·취소, Alt 거리 측정, 네이티브 페이지/내부 컨테이너 스크롤, 고정 A 보존과 B 재탐색, iframe/Shadow 경계, 삭제/이동/DevTools 종료 정리를 포함합니다. 도식 영역 라벨과 12개 테두리/여백/모서리 값, 작은 화면 잘림도 확인합니다.

Alt 재진입은 브라우저 입력(`isTrusted=true`)으로 반복·이동·스크롤 후 경로를 검사합니다. 포커스 복원 경합과 이벤트 취소 범위는 **합성 DOM 이벤트**로 따로 검사합니다. 보고서의 `altReentry`와 `altProtection`을 구분하세요. [재현 원인과 제한](0.3.22-alt-reentry.md)

## Figma 모의 호스트

빌드된 `code.js`를 VM에서 실행하고 `ui.html`을 브라우저 iframe에 연결합니다. 선택·비동기 추출의 역전 방지, 그림자 Inspect 근거, 실제 테스트 clipboard와 실패 복구, JSON 다운로드, 오류·재시도, 테마·접근성·좁은 화면을 확인합니다. 실제 Figma 앱 설치/실행을 재현한 시험은 아닙니다.

## 패키지

`npm run package`는 명시된 소스·빌드·문서·검증 증거만 ZIP에 포함하고 무결성 및 필수 설치 파일을 검사합니다. 결과는 `release/FigCheck-MVP-0.3.23.zip`과 SHA-256 파일입니다. ZIP·로그·캡처·의존성은 Git 추적 대상이 아닙니다. 빌드 해시는 `artifacts/verification-results.json`에 기록합니다.
