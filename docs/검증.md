# FigCheck 0.3.7 검증 안내

2026-10-05 Windows에서 Node.js 22.14.0과 격리된 Chrome for Testing 153.0.8010.12로 검증했습니다. 사용자 Chrome의 전역 설정이나 실제 확장 설치 상태는 바꾸지 않았습니다.

| 검증 | 결과·범위 |
|---|---|
| typecheck / lint / build | 모두 통과 |
| 핵심·adapter·host·commands 테스트 | 44개 통과 |
| 실제 Chrome 확장/DevTools 통합 | 99개 체크 통과 |
| Figma host VM + 실제 Chromium UI/clipboard | 60개 체크 통과 |
| 실제 Figma 데스크톱 호스트 | 미검증 |
| 물리적 OS 키 → Chrome commands 이벤트 | 미검증 |

실제 unpacked MV3 확장을 임시 프로필에 로드했습니다. DevTools FigCheck 패널, 파일/붙여넣기 JSON 검증, 안전한 이름 렌더링, 정상·차이·미지원 비교, 좁은 화면, 체크박스 포함 항목, CSSOM SecurityError, iframe/open Shadow DOM 제한, Elements 변경·삭제·navigation, 반복 선택·취소·Esc·클릭 차단·DevTools 종료 lease 정리를 확인했습니다.

commands는 Chrome이 Ctrl+Shift+X를 등록했음을 조회했습니다. 같은 빌드의 실제 명령 핸들러를 서비스워커에서 실행하여 아직 FigCheck를 한 번도 열지 않은 DevTools와 다른 패널 표시 상태에서 페이지 선택을 시작하고, 선택 후 FigCheck를 열면 결과가 연결됨을 확인했습니다. 다른 탭/만료 메시지 무시, 오래된 페이지 취소 요청이 새 start를 덮지 않는 경합 방지, DevTools가 닫혔을 때 F12 배지도 확인했습니다. 이는 물리적 키 이벤트가 commands로 발생했음을 증명하는 시험은 아닙니다. FigCheck 패널 포커스의 Ctrl+Shift+X는 실제 Chromium 키 입력으로 검증했습니다. 자동 탭 활성화는 Chromium의 userAction 제한 때문에 제공하지 않습니다.

Figma 시험은 빌드된 code.js를 VM에서 실행하고 빌드된 ui.html을 Chromium iframe에 연결한 mock입니다. 실제 clipboard 쓰기/차단/수동 복구·Ctrl+C, handshake, selectionchange, 단일 JSON 다운로드, stale 선택/늦은 복사/만료 요청, 무응답·예외·retry·close와 320px 화면을 확인했습니다. 빠른 연속 선택 중 extracting에서 이전 JSON이 즉시 비워지고 역순 도착한 이전 complete가 최신 JSON을 덮지 않음도 확인했습니다. 화면은 실제 Figma 호스트 캡처가 아닙니다. 예상 오류 주입 로그는 검증 결과에 남아 있으며 시험 실패를 뜻하지 않습니다.

두 UI를 중립 라이트/다크 배경·표면·글자와 아이보리 주요 동작의 공통 토큰으로 맞췄으며 empty/loading/complete/error/manual-copy, narrow·결과 화면을 직접 이미지로 확인했습니다. 테스트는 기본/보조/상태 텍스트와 단색 주동작에 대한 대비 4.5:1 이상을 확인합니다. 이는 모든 렌더 픽셀의 접근성 인증은 아닙니다.

기계 판독 결과와 화면은 `artifacts/verification-results.json`, `browser-results.json`, `plugin-browser-results.json`, PNG에 포함되어 있습니다. 빌드 해시는 verification-results에 기록합니다. 재현은 README의 verify 및 test:browser 명령을 사용하세요. 실제 Figma를 설치한 뒤 노드 선택→JSON 복사→Chrome 붙여넣기→페이지 선택을 마지막으로 확인하는 것이 남은 사용자 환경 시험입니다.

## 0.2.3 정밀도·새 UX 회귀

사용자 텍스트의 border width 0.6666669845581055 / 0.666667 및 동일 RGBA 네 면을 fixtures/precision-regression.json에 고정했습니다. strict/normal/사용자 수치 엔진 API 모두에서 border는 일치하고 width 282→420, height 450.5→588.5의 +138 차이는 유지합니다. Figma float32 normalized sRGB를 실제 extractor에 넣어 fractional 0~255 채널과 CSS rgb 파싱의 일치도 검증했습니다. 엔진의 preset API는 호환성을 위해 남겼고 UI 모드 선택은 제거했습니다.

실제 DOM #precision-report는 420×588.5 CSS px, 1px border와 rgb(222,226,230)입니다. 기본 비교 기준에서 사용자 디자인 JSON과 비교해 border가 불일치에서 빠지고 +138 두 크기만 남는 실제 DevTools 표시를 검증했습니다. 이 DOM의 1px은 사용자의 raw 0.666667px와 같지 않습니다. 정확한 두께 noise 값은 엔진 fixture로 별도 검증합니다. 사용자 실제 페이지나 실제 Figma 호스트를 재현했다는 의미는 아닙니다.

수치 epsilon 경계/그 너머, 큰 값에서도 고정 절대 오차, 미세하나 유의미한 차이 표시, NaN/Infinity/범위 밖 색·값, 미지원, 사용자 항목 제외와 전부 해제 시 null score, 키보드 Space/Tab, 그룹 indeterminate를 확인했습니다. 원본은 반올림하지 않습니다. 새 화면 PNG는 artifacts/figma-connection-complete.png, devtools-precision-regression.png, devtools-empty.png, devtools-narrow.png, figma-error.png 등에 있습니다. Figma 캡처는 mock임을 유의하세요.


## 0.2.3 도움말·화면 검증

양쪽 ? 버튼의 명확한 dialog label, Enter 열기, Tab 순환, Esc/닫기, trigger 포커스 복귀와 320px에서 height-bounded 스크롤을 확인했습니다. JSON에 ? 입력은 도움말을 열지 않습니다. 브라우저의 native dialog 기본 Tab 경계에서 일시적으로 body가 포커스되는 현상을 실제 시험에서 확인하여 명시적인 첫/마지막 제어 순환을 추가했습니다. Figma 연결 handshake·자동 추출·빠른 연속 선택·JSON 복사/복구/파일 저장·추출 오류와 Chrome 가져오기·수치 보정·포함 항목·picker 수명 회귀는 유지합니다.

DevTools 작업/도움말, Figma mock 작업/도움말과 오류 화면을 직접 이미지로 확인했습니다. 화면은 artifacts/devtools-panel.png, devtools-help.png, devtools-precision-regression.png, figma-connection-complete.png, figma-help.png, figma-error.png에 포함됩니다. Figma 실제 호스트는 시험하지 않았습니다.

한 브라우저 시험에서 테스트가 자체 페이지 picker owner를 교체한 뒤 navigation용 picker 재시작 대기가 한 차례 타임아웃되었습니다. 같은 조건의 재실행은 통과했으며 원인은 확정하지 못했습니다. 이를 제품 오류 해결로 주장하지 않습니다. 실제 사용자 페이지에서 해당 증상이 재현되면 추가 확인이 필요합니다.

## 0.2.9 로컬 글꼴·추가 정보·색상 표기

공식 Pretendard 1.3.9의 수정하지 않은 variable WOFF2 한 개와 SIL OFL 1.1 라이선스를 동봉했습니다. 실제 Chromium CSS.getPlatformFontsForNode로 한국어와 숫자의 custom Pretendard 글리프를 확인하고, 400/500/600 로딩·좁은 화면 줄바꿈을 검사했습니다. Figma는 data URL, Chrome은 확장 내부 font-src self로 로딩하며 원격 글꼴 요청이 없습니다. 자세한 원본 URL·해시는 packages/ui/fonts/source.json에 있습니다.

기본 표에 확인 불가 행이 섞이지 않는지, 평평한 추가 정보·돌아가기의 키보드와 포커스, 그룹 상태, 재선택·새로고침·모든 값 unknown/unsupported 회복을 검사했습니다. Figma의 전체 unknown/unsupported 사례는 UI 응답을 구성한 mock이며 실제 Figma 추출 결과로 주장하지 않습니다.

HEX/RGB/HSL 전환·키보드·로컬 재열기, alpha 0/1/중간값·회색 HSL·미세한 채널, 잘못된 RGBA 거부, 원본 JSON·score·delta 불변을 검사했습니다. 반올림은 표시만 적용합니다. font-results JSON과 additional-info/all-unknown/all-unsupported PNG도 artifacts에 포함됩니다. 실제 Figma 호스트와 OS 전역 단축키의 미검증 범위는 유지합니다.

## 0.2.11 차가운 무채색

거의 무채색인 UI 토큰의 RGB 채널 간 차이가 20 이하인지, 테마별 명도 반전 primary의 기본·hover·pressed 및 링크·아이콘·disabled 글자 대비 4.5:1 이상과 focus 대비 3:1 이상을 검사합니다. 실제 마우스 누름과 hover 상태를 theme-results JSON에 기록하고, Figma primary의 focus-visible은 실제 Tab 입력으로 확인합니다. 실제 색상 견본은 두 테마 간 동일합니다. 기존 39개 테스트, Chrome 89개 및 Figma mock 48개 회귀 항목을 실행합니다. 기존 저장 키·공통 비교 엔진·스키마·fixtures·Pretendard 자산은 변경하지 않습니다. 라이트·다크 비교 PNG는 원본을 1:1 크기로 합치고 원본 픽셀의 일치를 검사합니다.

## 0.3.3 영역·상태 회귀

실제 DevTools와 Figma mock의 라이트/다크·320px 화면에서 border→padding→크기 중첩, 네 모서리 순서, 기존 SVG 아이콘 재사용, 버튼 간 겹침 없음과 영역 밖 넘침 없음, 공통 크기 도식 폭, 방향 용어·접근성 이름을 확인합니다. 기본 목록의 성공 상태 열·중복 요약 제거와 상세 미지원 상태 보존, 기존 키보드·값·JSON·정밀도·테마·폰트·picker 회귀도 검증합니다. DevTools 자동화는 탐색/크기 변경 중 세션이 교체되는 경우 같은 URL/type 대상에만 한 번 재연결하며 제품의 assertion 실패는 재시도하지 않습니다.



## 0.3.3 모서리·색상 정렬 회귀

모서리 값과 공통 아이콘은 border 내부의 네 위치에 있으며 숫자 위의 독립 SVG 직사각형은 없습니다. border/padding 중첩은 남고 크기는 숫자로만 표시합니다. 실제 DevTools와 Figma mock에서 두 테마·320px의 N/A·긴 소수·매우 작은 크기·비대칭 모서리·키보드 행/이유 이동을 확인했습니다. Figma 표와 색상 미리보기에서 HEX/RGB/HSL 견본·값 우측 끝, 6px 간격, 라벨 비겹침과 JSON 불변을 확인했습니다. 크기 배율 도형을 제공한다는 이전 안내는 현재 도식에 적용되지 않습니다.


0.3.4 복사 버튼 검증: 실제 클립보드 내용 확인, 성공·대기·복귀 문구의 버튼 크기 유지, 별도 성공 문구 없음, 반복 성공의 타이머 교체, 선택 변경과 pagehide 정리, 이전 복사 응답 무효화, 실제 두 복사 실패 시 수동 복구를 검사했습니다. `artifacts/figma-copy-success.png`는 실제 Figma 호스트가 아닌 빌드 UI의 mock 캡처입니다.

두 앱의 실제 클립보드 시험은 순서대로 실행하세요. Windows 클립보드는 격리된 브라우저 프로필 사이에도 공유되어 병렬 시험의 복사 내용이 서로 영향을 줄 수 있습니다. `test:browser`는 두 시험을 순차 실행합니다.
