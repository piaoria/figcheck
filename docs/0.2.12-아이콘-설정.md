# FigCheck 0.2.12 아이콘·설정

메인 화면은 디자인/웹 요소의 이름, JSON 전달, 요소 선택과 비교 결과에 집중합니다. 차이만/전체 비교값은 결과 탐색이므로 표 옆에 유지합니다. 확인 불가 값의 이유는 기존 한 단계 자세히 보기에서 확인합니다.

## 헤더

- **해/달**: 현재 테마의 아이콘입니다. 해는 라이트, 달은 다크입니다. 클릭하면 반대 테마로 바뀝니다. 마우스 안내와 접근성 이름은 현재 테마와 다음 동작을 함께 알려줍니다. 테마 선택은 앱별로 그대로 저장됩니다.
- **톱니바퀴**: 설정을 엽니다. 설정은 한 단계이며 안에 또 접는 메뉴가 없습니다.
- **?**: 사용법·단축키·JSON 및 비교 한계를 안내합니다. 설정 조작은 도움말에 중복하지 않습니다.

## 설정

| 앱 | 설정 항목 |
|---|---|
| Figma | 색상 표기 HEX / RGB / HSL |
| Chrome DevTools | 색상 표기 HEX / RGB / HSL, 비교에 포함할 속성의 그룹/개별 체크 |

설정 변경은 즉시 반영됩니다. 색상 표기는 원본 RGBA·JSON·비교 판정을 바꾸지 않습니다. DevTools의 포함 체크는 기존처럼 비교 분모와 결과에 반영하며, 포함한 항목 중 양쪽 값이 비교 가능한 것만 점수에 들어갑니다. 설정 창을 닫아도 입력·선택·결과·열린 속성 그룹을 유지합니다. 설정을 열린 채로 Figma나 Elements 선택을 바꿔도 새 결과가 반영됩니다.

## 키보드·좁은 화면

Tab으로 헤더 아이콘에 이동하고 Enter/Space로 엽니다. 설정 안에서 Tab/Shift+Tab으로 조작합니다. **Esc 또는 닫기**는 창을 닫고 톱니바퀴로 포커스를 돌려줍니다. 설정과 도움말은 동시에 겹쳐 열리지 않습니다. 긴 설정은 창 안에서 스크롤하며 메인 화면에 가로 스크롤을 만들지 않습니다.

Chrome 확장을 새로고침하고 DevTools를 다시 여세요. Figma 플러그인을 닫고 같은 dist manifest로 다시 실행하세요. UI/host 버전 0.2.12를 확인합니다. [설치 안내](설치-사용.md)와 [검증 범위](검증.md)를 참고하세요.

차가운 무채색, Pretendard, 속성 아이콘, 원본 색상 견본과 기존 로컬 저장 키를 유지합니다. 실제 Figma 호스트와 OS 전역 단축키는 아직 미검증입니다.
