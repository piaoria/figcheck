# FigCheck 0.2.11 차가운 무채색 테마

두 앱을 차가운 흰색·회색·검정의 거의 무채색으로 구성합니다. 주요 **JSON 복사 / 요소 선택** 버튼은 테마별 명도 반전으로 강조합니다. 배경·선택·hover·focus·속성 아이콘과 일치 상태의 초록 강조는 제거했습니다. gradient·발광은 사용하지 않습니다.

| 상태 | 라이트 | 다크 |
|---|---|---|
| 배경 | #F7F8FA | #202328 |
| 기본 글자 | #20242A | #EEF1F5 |
| primary·선택 | #272C33 | #E5E9EF |
| primary 글자 | #FFFFFF | #20242A |
| hover | #3B424B | #FFFFFF |
| pressed | #15191E | #C7CFD9 |
| focus | #48515A | #D9E0E9 |
| disabled | 중립 회색 배경·글자 | 중립 회색 배경·글자 |

선택은 명도 반전과 텍스트/aria 상태, hover·pressed는 밝기, 키보드 focus는 얇은 윤곽선으로 식별합니다. 링크·아이콘도 무채색이며 오류·불일치의 빨간 계열만 절제해 유지합니다. 상태는 글자로 함께 안내합니다. **비교하는 실제 색상 견본은 원래 RGBA 색 그대로**입니다.

Pretendard 로컬 글꼴, 추출·비교 가능한 값 중심 표, 한 단계 자세히 보기, 속성 아이콘, 도움말, HEX/RGB/HSL 표시와 원본 RGBA·JSON·점수는 유지합니다. 이미 선택한 라이트/다크 및 색상 표기도 같은 앱별 저장 키를 사용합니다.

## 업데이트

Chrome 확장 화면에서 새로고침을 누르고 DevTools를 닫았다가 다시 여세요. Figma 플러그인을 닫고 같은 dist manifest로 다시 실행하세요. UI와 host 버전이 0.2.11인지 확인합니다. 자세한 순서는 [설치 안내](설치-사용.md)를 참고하세요.

## 검증 범위

두 테마의 primary 기본·hover·pressed 글자 대비, 링크·아이콘 대비, 키보드 focus·중립 disabled 상태와 거의 무채색인 토큰 범위를 수치 및 실제 Chromium 입력으로 확인합니다. 원본 색상 견본과 JSON·점수·기능·저장값·좁은 화면 검증도 실행합니다. 실제 Figma 호스트와 OS 전역 단축키는 미검증이며 Figma 이미지는 mock 호스트의 화면입니다. [검증 기록](검증.md)을 참고하세요.
