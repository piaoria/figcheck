# 0.3.11 · FigCheck 공통 로고

이 문서는 초기 단색 디자인 이력입니다. 현재 색상은 [0.3.12 로고 색상](0.3.12-brand-color.md)을 참고하세요.

두 겹의 사각 프레임은 디자인과 웹 요소를, 안쪽 체크는 비교·확인을 뜻합니다. 자체 제작한 단색 기하 심볼이며 타사 로고·폰트·이미지를 사용하지 않습니다.

## 적용

- Figma 플러그인과 DevTools 결과 아래 기존 푸터에 20px 공통 심볼. 상단 브랜드 헤더는 추가하지 않습니다.
- SVG는 currentColor로 기존 cool monochrome light/dark 테마를 따릅니다. 옆의 FigCheck 텍스트가 이름을 전달하므로 SVG는 aria-hidden/focusable=false입니다.
- Chrome manifest icons와 action.default_icon에 16/32/48/128px PNG, DevTools panels.create에 32px PNG를 연결합니다. Chrome 버전에 따라 DevTools 탭 아이콘 자체는 표시되지 않을 수 있습니다.
- Figma manifest에 지원되지 않는 icon 필드는 추가하지 않았습니다. 512px PNG는 향후 커뮤니티 게시를 위한 로컬 준비 파일이며 게시하지 않았습니다.

## 원본과 재생성

원본: packages/ui/brand/mark.svg

scripts/brand-icons.mjs는 원본 기하를 재사용해 단색 배지 SVG와 PNG를 생성합니다. 새 라이브러리 없이 기존 Playwright와 설치된 브라우저를 이용합니다. npm run build에서 자동 실행하며 FIGCHECK_BROWSER_PATH로 기존 브라우저 실행 파일을 지정할 수 있습니다. Windows에서는 설치된 Edge도 탐색합니다. 자동 브라우저 설치는 하지 않습니다.

생성 파일: packages/ui/brand/generated/app-icon.svg 및 icon-16/32/48/128/512.png. 확장 dist/icons에는 16/32/48/128을 복사합니다. 양쪽 HTML은 빌드 시 같은 SVG를 인라인 삽입합니다.

## 검증과 로컬 확인

npm run verify / node scripts/brand-review.mjs / npm run test:browser.

brand-review는 PNG 실제 치수, manifest/action/DevTools 참조, 동일 푸터 SVG, Figma 임의 필드 부재를 확인하고 artifacts/brand-icons-light.png 및 brand-icons-dark.png를 저장합니다. 실제 Edge DevTools와 Figma host mock UI의 light/dark 푸터도 회귀검사·캡처합니다. 실제 Figma 호스트는 검증하지 않았습니다.

Chrome 확장 관리에서 기존 확장을 새로고침하고 DevTools를 닫았다 다시 열면 됩니다. 툴바 아이콘은 확장을 고정하면 확인할 수 있습니다. Figma는 apps/figma-plugin/dist/manifest.json을 개발 플러그인으로 불러온 뒤 재실행합니다. 결과 아래로 스크롤해 양쪽 푸터를 확인하고 테마 버튼으로 밝음/어두움을 전환합니다.
