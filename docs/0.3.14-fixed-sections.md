# 0.3.14 · 고정 속성 섹션

현재 화면의 상위 속성 details와 그 안의 구조/색상/글꼴 preview details가 중첩되어 포함 관계가 모호했습니다.

- 제거: 모든 주요 속성 카테고리 접기, 영역 구조 접기, 중복 색상/글꼴 미리보기.
- 고정: 크기·여백/간격·색상·타이포그래피·테두리/모서리·불투명도·그림자를 같은 수준의 h2 섹션으로 표시. 지원 속성만 기본 표에 표시합니다.
- 영역 구조는 크기의 h3 하위영역이며 얕은 들여쓰기와 왼쪽 선으로 포함 관계를 표현합니다. Border 안의 Padding/크기와 네 Radius는 항상 보입니다. 인접 h2 그룹은 위 구분선과 간격으로 분리합니다.
- 유지: JSON 보기, 긴 원본 그림자 근거 details, 진단 details. 미지원 속성은 기존 한 단계 추가 정보 화면/돌아가기이며 중첩 아코디언은 아닙니다. 그림자 없음/미수집/비교불가/원본값은 기존 표현을 보존합니다.

중복 색상/글꼴 미리보기를 없애 같은 값을 반복하지 않습니다. 색상 우측 정렬·단색 테마·Pretendard·선택노드 한줄 액션·4색 코너 로고·복사피드백을 유지합니다. 추출값·비교점수·JSON 스키마는 변경하지 않습니다.

변경 CSS는 apps/figma-plugin/ui.html에만 있으며 공유 테마/visual-preview 구현은 변경하지 않습니다. 익스텐션 기존 disclosure는 유지합니다.

검증: npm run verify 및 npm run test:browser. 최소320px·양테마·긴이름·빈/오류·많고 적은 속성·원본JSON·색상표기·복사/키보드 복구·그림자 상태 검사. 실제 Figma 호스트는 별도 확인 대상입니다. artifacts/figma-properties.png 및 figma-theme-light-narrow.png / figma-theme-dark-narrow.png에서 최종 화면을 확인할 수 있습니다.
