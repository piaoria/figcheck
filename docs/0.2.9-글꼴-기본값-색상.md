# FigCheck 0.2.9 글꼴·기본 표·색상 표기

## 당장 확인할 값부터

Figma의 기본 속성 표에는 **추출된 값만** 표시합니다. 값이 있는 분류만 보이며 분류별 숫자는 현재 표시할 수 있는 추출 개수입니다. 정상적인 `0` 값도 표시합니다. 추출 안 됨·미지원·속성 없음과 이유는 **자세히 보기**의 한 단계로 모았습니다. 그 화면에는 중첩 접기가 없으며 **추출된 값으로 돌아가기**로 복귀합니다.

추출 값이 하나도 없으면 빈 표 대신 짧은 상태와 자세히 보기·다른 노드 선택 안내를 표시합니다. 상단에는 추출 개수와 추가 정보 개수만 간결히 표시합니다. JSON 복사·파일 저장·JSON 보기에는 원래 28개 속성의 상태와 이유가 그대로 남습니다. 선택이 바뀌면 이전 JSON·추출 상세를 무효화하고 새 기본 결과를 표시합니다. 사용자가 정한 분류 접힘 상태와 테마 선택은 유지합니다.

DevTools의 **차이만**은 비교 가능한 항목 중 차이를, **전체 비교값**은 포함한 항목 중 실제 비교 가능한 전체 값을 표시합니다. 미지원·값 미확인·값 오류·사용자 제외는 기본 표에 섞지 않고 **자세히 보기**에서 구분합니다. **비교 결과로 돌아가기**로 복귀합니다. 이 화면의 분류·원본 정보는 단일 화면으로 펼쳐져 있습니다.

아래 포함 체크는 비교할 항목을 요청하는 설정입니다. 체크되어 있어도 양쪽 값을 비교할 수 없으면 표와 점수에서 제외됩니다. 사용자가 체크를 해제한 항목은 별도로 사용자 제외로 설명합니다. 점수 분모는 비교 가능한 항목만이며, 비교 가능한 값이 0개일 때 점수를 표시하지 않습니다. CSS 근거는 기존의 별도 후보 정보로 유지하며 확정 원인으로 꾸미지 않습니다.

## Pretendard를 오프라인으로

UI의 기본 글꼴은 **Pretendard Variable 1.3.9**입니다. 공식 저장소의 변경하지 않은 가변 WOFF2 한 파일만 번들하고, UI가 쓰는 400–600 굵기를 선언했습니다. 9개 굵기 파일이나 외부 글꼴 패키지를 추가하지 않습니다. 임의의 한글 노드 이름도 표시해야 하므로 UI 문구만의 제한된 글자 목록으로 자르지 않았습니다.

Figma UI에는 글꼴을 data URL로 내장합니다. Chrome 확장은 로컬 `fonts/PretendardVariable.woff2`에서 읽으며 `font-src 'self'`를 사용합니다. 실행 중 CDN 호출이나 새 권한은 없습니다. 라이선스와 공식 출처·체크섬은 `packages/ui/fonts/LICENSE`, `source.json`에 있고 설치용 dist에도 라이선스를 포함합니다.

기존 `-apple-system, BlinkMacSystemFont, Segoe UI, Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR, sans-serif` fallback은 같은 순서로 남아 있습니다. 글꼴 로딩 실패나 포함되지 않은 글자는 이 fallback을 사용할 수 있습니다. 원본 JSON·CSS 자료용 코드 영역의 monospace는 유지합니다. UI 글꼴 변경은 선택한 Figma 노드나 웹 DOM의 글꼴을 수정하지 않습니다.

공식 출처: [Pretendard 저장소](https://github.com/orioncactus/pretendard), [1.3.9 SIL Open Font License 1.1](https://github.com/orioncactus/pretendard/blob/v1.3.9/LICENSE).

## HEX / RGB / HSL

두 앱의 **색상 표기** 설정에는 대표 3개 형식만 있습니다. 기본은 RGB이며 선택은 앱별 로컬 저장소에 기억합니다. Tab과 방향키로 선택합니다. 테마와 별도 설정이며 표기만 바꾸므로 입력·비교 결과·열린 분류·자세히 보기 상태가 바뀌지 않습니다.

- **HEX**: 불투명은 `#RRGGBB`, 투명도가 있으면 `#RRGGBBAA`입니다. RGB 채널과 `alpha × 255`를 가장 가까운 정수로 반올림합니다. 예를 들어 alpha `0.5`는 `80`이므로 표시값을 역변환하면 원본과 작은 차이가 있을 수 있습니다. alpha가 1보다 작으면 반올림 결과가 `FF`여도 8자리를 표시합니다.
- **RGB**: 불투명은 `rgb(...)`, alpha가 있으면 `rgba(...)`입니다. RGB 채널은 소수 셋째 자리, alpha는 여섯째 자리까지 표시합니다. 아주 작은 0이 아닌 값은 0으로 지우지 않고 과학 표기를 사용합니다.
- **HSL**: 불투명은 `hsl(...)`, alpha가 있으면 `hsla(...)`입니다. hue·saturation·lightness는 소수 셋째 자리까지, alpha는 RGB와 같은 방식으로 표시합니다. 무채색의 hue는 0입니다.

표·색 견본 설명·보조 상세는 선택한 표기를 사용합니다. 표기는 원본 RGBA에서 매번 계산하므로 HEX → HSL → RGB를 반복해도 누적 오차가 없습니다. **원본 값**의 JSON과 export는 변경하지 않습니다. 색 차이의 delta와 비교 기준은 표기 설정과 관계없이 원래 sRGB 채널·alpha 기준입니다. 미지원 색이나 sRGB 범위를 벗어난 값은 임의로 변환하지 않습니다.

검증에서는 검정·흰색·무채색·기본 색·반투명·alpha 0/1·가까운 소수 값·유효하지 않은 값, 원본과 비교 결과 불변, 저장 복원, 키보드·좁은 화면을 확인합니다. 실제 Figma 호스트와 물리적 OS 단축키는 기존과 같이 미검증이며, Figma 화면은 빌드된 host VM + 실제 Chromium UI mock입니다. [전체 검증 안내](검증.md)를 참고하세요.
