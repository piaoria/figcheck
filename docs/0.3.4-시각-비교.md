# FigCheck 0.3.4 사용 안내

Chrome DevTools의 시각 미리보기는 처음에 Web만 표시합니다. 지구 아이콘은 항상 Web을 표시하며, Figma 아이콘을 누르면 디자인과 Web을 함께 봅니다. 다시 누르면 Web만 봅니다. 버튼 배경과 눌림 상태로 현재 보기를 확인할 수 있으며 Tab과 Enter/Space로 조작할 수 있습니다. 디자인 JSON이 없으면 Figma 버튼에서 먼저 디자인을 적용하라는 안내를 표시합니다. 미리보기의 보기 방식만 바뀌며 비교 표·점수는 선택한 Figma 디자인과 Web의 비교를 유지합니다.

Border, Padding, Radius는 구조 영역 이름입니다. 크기와 간격은 원본 숫자로 읽으세요. 구조 도식은 비례 렌더링이 아니며 곡선을 실제 radius대로 그리지 않습니다. 지원되지 않는 값은 N/A와 이유로 표시하고 점수에서 제외합니다. 색상과 글꼴 미리보기도 기본적으로 Web 한 쪽만 표시하며 비교 값은 함께 보기와 속성 표에서 확인할 수 있습니다.

Figma에서 **JSON 복사**를 누르면 현재 속성 화면과 그룹 상태·스크롤을 유지하고 버튼 문구를 2.5초 동안 복사 완료로 바꾸며 별도 성공 문구를 표시하지 않습니다. 클립보드 API가 막힌 경우 실제 선택 텍스트 복사를 시도합니다. 두 방법이 모두 실패해야 읽기 전용 JSON을 선택한 수동 복사 화면을 표시합니다. 이 경우 완료 안내를 표시하지 않습니다. 선택이 바뀌거나 복사를 반복해도 이전 응답이 새 선택의 안내를 덮어쓰지 않도록 처리합니다.

Chrome의 첫 입력 화면에 복사한 JSON을 붙여 넣고 **디자인 적용**을 누르세요. 입력 중에는 자동 검사·자동 적용·자동 화면 이동이 없습니다. Ctrl+Enter(macOS에서는 Command+Enter)로 적용할 수도 있습니다. 성공하면 디자인 요약으로 초점이 이동하며 선택한 Web 요소를 유지합니다. 적용된 디자인은 **디자인 변경**에서 다시 편집할 수 있습니다. 취소 또는 Escape는 초안만 버리고 기존 디자인·비교를 유지하며 진입 버튼으로 초점을 돌립니다.

잘못된 JSON은 입력칸 옆에 이유를 표시하고 초안·기존 비교를 보존합니다. 수정 후 다시 적용하세요. 파일 가져오기도 동일한 스키마 검사를 사용하며 실패 시 기존 디자인을 유지합니다. 파일 읽기가 진행 중일 때 붙여넣기를 적용하면 이전 파일 결과가 뒤늦게 덮어쓰지 않습니다. 클립보드를 자동으로 읽지 않습니다.

이전 화면에서 붙여넣기 진입 버튼, 펼침 제목, 빈 상태 버튼이 겹쳐 보였고 취소 후 숨겨진 입력칸에 초점이 남을 수 있었습니다. 이번 버전은 입력 화면이 열리면 별도의 진입 버튼을 숨기고 적용·취소 후 알맞은 위치로 초점을 이동합니다. 설정과 도움말 아이콘은 같은 무채색·크기·hover·focus를 사용하며 테두리 없이 표시합니다. 저장한 테마와 색상 표기 설정은 유지합니다.

실제 Chrome 확장은 격리 프로필에서 DevTools 패널을 열어 검증했습니다. Figma 검증은 빌드된 호스트 코드를 공식 API 타입과 mock 환경에 연결한 시험이며 실제 Figma 앱에서의 시험을 대신하지 않습니다. 사용자 Chrome의 전역 설정이나 설치된 확장을 변경하지 않습니다. 설치 경로와 방법은 [설치·사용](설치-사용.md), 비교 가능 범위는 [비교 한계](비교-한계.md)를 확인하세요.
