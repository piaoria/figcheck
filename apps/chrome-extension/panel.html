처음 사용

  1. 요소 선택으로 웹의 DOM 하나를 클릭하면 영역 구조와 속성을 바로 확인합니다.
  2. Alt+hover로 다른 요소와 거리를 확인합니다. 선택한 요소의 값은 자동 갱신됩니다.
  3. 비교가 필요할 때 Figma JSON을 붙여넣거나 파일로 가져옵니다. 선택한 Web은 유지됩니다.

디자인과 웹을 직접 각각 선택합니다. 자동 매칭은 없습니다. 완료된 입력은 요약으로 접히고 결과는 자동 갱신됩니다.

JSON 전달

입력 중에는 적용하지 않습니다. 디자인 적용 또는 Ctrl/Command+Enter로 검사·적용하고, 취소 또는 Escape로 초안만 버립니다. 성공하면 디자인 요약으로 이동하며 선택한 Web은 유지합니다.

파일 저장과 가져오기도 지원합니다. JSON schemaVersion은 1.0이며 앱 버전과 별개입니다. Figma는 한 노드를 내보내고, 여러 노드/nested JSON은 노드 목록에서 수동 선택합니다.

JSON 원문은 JSON 보기에서 확인합니다. 복사와 파일 저장은 표 화면에서 가능합니다. 선택이 바뀌면 이전 표와 JSON은 즉시 무효화됩니다. 속성만 수정했다면 새로 추출합니다. 복사가 차단되면 다시 복사 또는 선택된 JSON에서 Ctrl+C를 사용하세요.

잘못된 붙여넣기는 기존 디자인을 유지합니다. 잘못된 파일도 기존 디자인을 유지합니다. 비우기는 로컬에 저장한 디자인을 삭제합니다. 분석 데이터는 외부로 전송하지 않습니다.

단축키

Ctrl+Shift+X
DevTools가 열린 페이지에서 요소 선택 켜기/끄기. 다른 DevTools 탭에서도 시작하며 결과는 FigCheck 탭을 열어 확인합니다. 닫혀 있으면 툴바에 F12 안내가 나타납니다.
↑ / ↓
요소 선택 중 부모 / 이전 자식 탐색. Alt+휠을 포함한 휠 입력은 페이지 스크롤에 그대로 전달합니다. 같은 요소 위의 포인터 이동은 깊이를 유지합니다. 클릭 또는 Enter로 확정합니다. 입력 필드에 포커스가 있으면 방향키·Enter는 입력에 사용합니다.
클릭 후 Alt+hover
A의 윤곽과 정보를 고정하고 B와의 CSS px 박스 경계 거리를 표시합니다. Alt를 떼면 A만 남고 Esc는 표시만 종료합니다. 휠은 선택·측정 중 모두 페이지 스크롤이며 margin/padding 선언값이 아닙니다.
Esc
도움말을 닫거나 요소 선택을 취소합니다.
Ctrl+V / Ctrl+C
JSON 붙여넣기 / 복사. Mac에서는 ⌘를 사용합니다.

키 충돌은 chrome://extensions/shortcuts에서 확인합니다. OS 전역 단축키가 아닙니다.

속성 시각 비교

기본 미리보기는 Web만 표시합니다. Figma 아이콘으로 함께 보기를 켜거나 끌 수 있습니다. Web은 항상 표시하며 표와 점수는 디자인과 비교합니다.

크기·간격·테두리 도식, 색상 견본, 글꼴 속성 요약을 펼쳐 봅니다. 실제 크기는 숫자로 표시합니다. Border 안에 Padding을 중첩하고 Radius 값은 테두리의 네 모서리에 표시합니다. 중첩 영역은 비례·배율 도형이 아닌 기호이며 실제 UI를 재현하지 않습니다. 수치 버튼은 표의 속성 또는 추가 정보로 이동합니다.

N/A는 0이 아닙니다. 미지원·사용자 제외 이유는 추가 정보에서 확인합니다. Figma content는 stroke/layout 포함 정보가 없어 역산하지 않습니다. 웹 content는 모든 관련 값과 box-sizing·스크롤바 조건이 확인될 때만 계산합니다. margin은 생략하며 gap을 padding으로 대신하지 않습니다. 색상은 원본 alpha와 체크무늬를 유지하고 실제 폰트 예문은 렌더링하지 않습니다.

비교 범위

크기, padding 4방향, row/column gap, 글꼴 5항목, 글자, 배경색, 테두리 4면 두께, 색, 모서리 4개 radius, 자체 opacity를 비교합니다. 일반 박스 그림자는 Inspect CSS 근거가 있는 NORMAL 외부/내부 효과만 비교합니다. 하위 노드 전체, layer/background blur, filter, 이미지, 배치는 분석하지 않습니다.

체크 해제는 사용자 제외, unknown은 값 미확인, unsupported는 미지원으로 표시합니다. 둘 다 점수 분모에서 빠지며 전부 제외하면 점수가 없습니다. 크기, 여백 ±1px, 글꼴 수치 ±0.5px, RGB 각 채널 ±1, alpha/opacity ±0.01의 기본 기준을 적용합니다. 미세 표현 오차는 별도 보정하며 원본은 유지합니다.

mixed, 복합 paint, gradient, 미해결 normal/auto/%/calc, transform/zoom 등은 속성별 이유를 표시합니다. 단일 HTML 요소만 선택하며 iframe/SVG/open Shadow 내부는 제한됩니다. CSS 규칙은 후보이고 cascade 승자, source line, Tailwind 원인을 추정하지 않습니다. 교차 출처 CSS는 접근이 제한될 수 있습니다.

실제 Figma 호스트와 OS 키의 Chrome command 이벤트는 아직 시험하지 않았습니다. Figma 화면 시험은 mock, Chrome 비교는 격리된 실제 확장 환경입니다.
